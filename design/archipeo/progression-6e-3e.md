# Progression 6e → 3e

## Principe

La progression doit évoluer avec l'âge du joueur sans rendre l'interface ou l'univers plus enfantin en 6e et plus sérieux en 3e.

L'évolution doit surtout porter sur :

- l'autonomie ;
- la complexité des objectifs ;
- la longueur des chaînes de missions ;
- la combinaison de compétences ;
- la profondeur narrative.

## 6e — Découverte

### Expérience

Le joueur apprend les règles du monde.

### Game design

- objectifs explicites ;
- chemins relativement guidés ;
- constructions simples ;
- feedback fréquent ;
- découverte des mécaniques.

### Narration

Le joueur découvre l'histoire de l'archipel.

## 5e — Exploration

### Expérience

Le joueur commence à choisir ses itinéraires.

### Game design

- plusieurs zones accessibles ;
- missions légèrement plus ouvertes ;
- chemins alternatifs ;
- constructions plus complexes.

### Narration

Le joueur découvre que l'archipel possède une histoire plus profonde.

## 4e — Maîtrise

### Expérience

Le joueur mobilise plusieurs compétences.

### Game design

- chaînes de missions ;
- problèmes multi-étapes ;
- mécanismes ;
- infrastructures complexes ;
- exploration moins guidée.

### Narration

Le joueur restaure les systèmes anciens qui reliaient les îles.

## 3e — Accomplissement

### Expérience

Le joueur est autonome et mobilise ses acquis.

### Game design

- missions intégrant plusieurs compétences ;
- objectifs à plus long terme ;
- constructions majeures ;
- exploration plus libre.

### Narration

Le joueur prépare l'avenir de l'archipel et construit le lien entre les différentes régions.

## Principe d'âge

Un élève de 3e doit pouvoir jouer à Blocland sans ressentir que l'univers est destiné aux enfants.

La maturité doit venir du :

- scénario ;
- design des environnements ;
- niveau de défi ;
- autonomie ;
- profondeur des objectifs.

Pas de l'ajout de contenus sombres ou anxiogènes.
