# Game Design

## Boucle de jeu principale

1. Explorer une zone.
2. Identifier une mission.
3. Réaliser une activité pédagogique.
4. Recevoir une correction ou une aide.
5. Obtenir une ressource, un bloc ou une progression.
6. Utiliser cette progression dans le monde.
7. Débloquer une nouvelle zone.

## Principe central

> Une réussite pédagogique doit pouvoir produire une conséquence visible dans l'univers lorsque cela est pertinent.

Exemples :

- réparer une passerelle ;
- reconstruire un mur ;
- rallumer un phare ;
- restaurer un atelier ;
- ouvrir un passage ;
- améliorer un bâtiment.

## Les blocs

Les blocs sont à la fois :

- une récompense ;
- une ressource ;
- un langage visuel ;
- un élément de construction.

Ils doivent avoir une apparence cohérente avec l'architecture de l'île.

## Le village

Le village constitue le lieu de progression principal.

Il doit évoluer progressivement :

### État 1 — Abandonné

Quelques bâtiments incomplets et infrastructures dégradées.

### État 2 — Réactivation

Premiers bâtiments réparés, chemins praticables.

### État 3 — Reconstruction

Village habité et relié.

### État 4 — Développement

Nouveaux bâtiments et infrastructures.

### État 5 — Port

Le village dispose d'un port permettant de rejoindre l'archipel suivant.

## Le Bloc-Navire

Le navire est un objectif de moyen/long terme.

Sa construction doit être visible morceau par morceau.

Étapes possibles :

1. coque ;
2. pont ;
3. mât ;
4. voiles ;
5. instruments de navigation ;
6. décoration ;
7. lancement.

## Objectifs à trois échelles

### Court terme

Réussir une mission.

### Moyen terme

Réparer un bâtiment ou une infrastructure.

### Long terme

Restaurer le village et construire le Bloc-Navire.

## Récompenses

Privilégier les récompenses ayant une fonction dans le monde.

### Récompenses de progression

- blocs ;
- nouvelles constructions ;
- nouvelles zones ;
- nouveaux éléments de personnalisation.

### Récompenses de reconnaissance

- XP ;
- rangs ;
- succès.

Ces systèmes ne doivent pas se multiplier inutilement.

## Rangs

Les rangs peuvent représenter des rôles dans l'univers :

- Explorateur ;
- Cartographe ;
- Bâtisseur ;
- Navigateur ;
- Architecte de l'archipel.

Ils valorisent la progression et non uniquement la performance.

## Personnalisation

À terme, permettre de personnaliser :

- certains bâtiments ;
- éléments décoratifs ;
- organisation du village ;
- apparence du navire ;
- nom du navire.

Les choix cosmétiques ne doivent pas modifier la difficulté pédagogique.

## Erreur

L'erreur doit être informative.

Après une erreur :

1. signaler calmement le résultat ;
2. expliquer ou mettre en évidence le point important ;
3. proposer un indice si nécessaire ;
4. permettre une nouvelle tentative.

Pas de perte de progression.

## Temps

Ne pas utiliser de chronomètre obligatoire pour créer de la pression.

Le temps peut éventuellement exister comme élément optionnel ou purement esthétique, mais pas comme mécanisme de sanction.

## Vie du monde

Ajouter progressivement :

- passages de baleines ;
- vols d'oiseaux ;
- météo légère ;
- changements de lumière ;
- activation de phares ;
- bateaux à l'horizon ;
- nouvelles constructions visibles.

Le monde doit sembler évoluer même lorsque le joueur ne fait pas directement une mission.
