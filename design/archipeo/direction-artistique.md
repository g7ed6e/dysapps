# Direction artistique

## Intention

Créer un univers d'aventure maritime stylisé, mystérieux et chaleureux, avec une esthétique suffisamment mature pour accompagner un collégien pendant plusieurs années.

### Direction proposée

**Low-poly aventure / exploration**

Références de langage visuel :

- volumes simples et lisibles ;
- silhouettes fortes ;
- architecture modulaire ;
- paysages maritimes ;
- falaises, ruines, villages et phares ;
- lumière atmosphérique ;
- brume légère ;
- horizon profond ;
- créatures majestueuses.

L'objectif n'est pas le réalisme mais une identité graphique cohérente et durable.

## À éviter

- esthétique préscolaire ;
- gros yeux et mascottes excessivement mignonnes ;
- couleurs pastel omniprésentes ;
- boutons ressemblant à des jouets ;
- pluie de confettis à chaque réussite ;
- effets visuels agressifs ;
- interface trop chargée.

## Les cinq piliers visuels

### 1. Des îles avec du caractère

Chaque île doit avoir une silhouette et quelques éléments architecturaux immédiatement reconnaissables.

### 2. Une construction visible

Les matériaux doivent appartenir à une architecture cohérente :

- bois ;
- pierre ;
- métal ;
- passerelles ;
- tours ;
- ateliers ;
- quais ;
- phares.

### 3. Une faune majestueuse

La baleine est une présence importante mais pas une mascotte omniprésente.

Les oiseaux donnent de la vie aux scènes et peuvent servir de repères visuels.

### 4. Une atmosphère d'exploration

Utiliser :

- variations de lumière ;
- brume ;
- météo légère ;
- mouvements de l'océan ;
- oiseaux au loin ;
- baleine apparaissant occasionnellement.

### 5. Une interface moderne

Les panneaux UI doivent être :

- sobres ;
- contrastés ;
- lisibles ;
- géométriques ;
- cohérents avec l'architecture du monde.

## Règle DA-01 — Âge cible

Toute nouvelle illustration doit pouvoir être montrée à un élève de 3e sans donner l'impression d'un produit destiné aux jeunes enfants.

## Règle DA-02 — Lisibilité

Le décor ne doit jamais rendre une consigne ou une information pédagogique difficile à lire.

## Règle DA-03 — Cohérence

Les éléments construits par le joueur doivent sembler appartenir au même monde architectural.

## Règle DA-04 — Progression visible

La restauration d'une zone doit être perceptible avant/après.

## Règle DA-05 — Retenue

Les célébrations doivent rester élégantes : transformation du décor, son court, lumière, animation discrète.
