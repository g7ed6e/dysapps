# Univers de Blocland

## Le monde

L'archipel de Blocland était autrefois relié par un vaste réseau de villages, de ponts, de ports et de phares.

Un événement ancien a fragmenté les territoires.

Les routes ont disparu, les infrastructures se sont dégradées et certaines îles se sont retrouvées isolées.

Le joueur participe à la restauration progressive de cet archipel.

## La baleine

La baleine est la figure tutélaire de l'univers.

Elle n'est pas une mascotte scolaire.

### Rôle

- guider occasionnellement le joueur ;
- signaler des découvertes ;
- donner des indices ;
- commenter les grandes étapes ;
- accompagner certaines traversées.

### Personnalité

- calme ;
- mystérieuse ;
- bienveillante ;
- légèrement malicieuse ;
- jamais infantilisante.

### Exemples de dialogues

**Arrivée**

> Le village n'est plus relié au port. Tu peux nous aider à reconstruire le passage.

**Réussite**

> Bien joué. Une nouvelle partie du pont est en place.

**Hésitation**

> Regarde le plan. Quel élément pourrait t'aider à commencer ?

**Erreur**

> Pas grave. On peut essayer autrement. Voici un indice.

**Progression**

> Le phare est de nouveau visible depuis la mer. Une nouvelle route s'ouvre.

## Les oiseaux

Les oiseaux donnent une sensation de vie à l'archipel.

Ils peuvent :

- se déplacer entre les îles ;
- accompagner le joueur ;
- transporter des messages ;
- signaler une zone active ;
- créer des mouvements dans le ciel.

Ils doivent rester des éléments environnementaux autant que des outils de game design.

## Les quatre archipels

### 6e — Les Premiers Rivages

Thème : découverte.

- petites îles ;
- villages côtiers ;
- premiers ponts ;
- phares ;
- ruines accessibles ;
- constructions simples.

Le joueur apprend les règles du monde.

### 5e — L'Archipel des Brumes

Thème : exploration.

- îles plus éloignées ;
- forêts ;
- reliefs ;
- passerelles suspendues ;
- observatoires ;
- chemins cachés.

Le joueur devient plus autonome.

### 4e — Les Anciens Ateliers

Thème : maîtrise.

- anciennes installations ;
- mécanismes ;
- ateliers ;
- structures métalliques ;
- constructions complexes.

Le monde demande davantage de raisonnement.

### 3e — L'Archipel de l'Horizon

Thème : accomplissement.

- structures monumentales ;
- grand port ;
- phare central ;
- navire complet ;
- vues sur les archipels précédents.

Le monde doit donner une impression d'aboutissement et d'ouverture vers la suite.

## Les trois domaines

### Mathématiques — Les mécanismes

Métaphore : comprendre comment le monde fonctionne.

Les mathématiques peuvent être associées à :

- mécanismes ;
- ponts ;
- plans ;
- dimensions ;
- matériaux ;
- structures ;
- énigmes.

### Français — Les archives

Métaphore : comprendre les traces laissées par les habitants.

Le joueur peut :

- déchiffrer des archives ;
- reconstituer des récits ;
- restaurer des inscriptions ;
- comprendre des messages ;
- retrouver des informations.

### Anglais — Les routes maritimes

Métaphore : communiquer avec les autres explorateurs.

Le joueur peut :

- lire des cartes ;
- comprendre des messages ;
- écouter des communications ;
- interagir avec des voyageurs ;
- retrouver une destination.
