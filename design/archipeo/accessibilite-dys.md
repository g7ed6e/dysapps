# Accessibilité Dys

## Philosophie

L'accessibilité n'est pas un mode séparé du jeu.

Elle doit être intégrée au design général.

## Principes à préserver

- police Luciole lorsque pertinente ;
- taille de texte confortable ;
- consignes audio ;
- syllabes colorées lorsque pédagogiquement pertinentes ;
- une tâche principale par écran ;
- aides visuelles ;
- indices sans pénalité ;
- absence de chronomètre obligatoire ;
- corrections explicatives ;
- navigation prévisible.

## Règle ACCESS-01 — Une consigne = une action principale

Éviter les écrans qui demandent simultanément plusieurs actions non liées.

## Règle ACCESS-02 — Audio

Toute consigne importante devrait pouvoir être écoutée.

L'audio doit être activable sans chercher dans un menu complexe.

## Règle ACCESS-03 — Ne jamais dépendre uniquement de la couleur

Une information importante doit être transmise par au moins un autre canal :

- texte ;
- icône ;
- forme ;
- position ;
- animation ;
- son.

## Règle ACCESS-04 — Réduction de la charge visuelle

Les zones pédagogiques doivent rester calmes même lorsque le décor est riche.

## Règle ACCESS-05 — Pas de punition de l'erreur

L'échec d'un exercice ne doit pas supprimer une progression déjà acquise.

## Règle ACCESS-06 — Indices

Un indice doit aider à comprendre la méthode, pas simplement donner la réponse.

## Mode concentration

Proposer un réglage permettant de :

- réduire les animations décoratives ;
- diminuer les mouvements ;
- réduire les effets sonores ;
- masquer certaines informations secondaires ;
- désactiver les célébrations visuelles.

Ce mode ne doit pas être présenté comme un mode « pour dys », mais comme une préférence de confort disponible pour tous.
