# Police Luciole

Luciole est la police recommandée pour les élèves malvoyants et dys (licence Creative Commons BY 4.0, Laurent Bourcellier et Jonathan Perez, avec le Centre Technique Régional pour la Déficience Visuelle).

Elle n’est pas distribuée sur npm : déposez ici les fichiers téléchargés sur le site officiel (luciole-vision.com), avec exactement ces noms :

- `Luciole-Regular.woff2`
- `Luciole-Bold.woff2`

(Les versions `.ttf` fonctionnent aussi si vous adaptez `src/styles/global.css`.)

Dès que les fichiers sont présents, l’option « Luciole » des réglages s’active, et vous pouvez la mettre par défaut dans `src/core/settings.ts` (`DEFAULT_SETTINGS.font`).
