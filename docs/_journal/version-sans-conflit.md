**Des numéros de version calculés, plus écrits.** La version n’est plus inscrite dans le dépôt : elle se calcule depuis l’historique, à la manière de GitVersion. Chaque pull request fusionnée monte la version mineure (ou un autre cran, si son message le demande par `+semver: major`, `+semver: patch` ou `+semver: none`), et une étiquette `vX.Y.Z` marque chaque publication. Le journal suit le même principe : chaque pull request ajoute un fragment dans `docs/_journal/`, et le numéro et la date de l’entrée sont ajoutés à la publication. Deux pull requests menées en parallèle n’ont plus à se rebaser l’une sur l’autre pour la version. Rien ne change dans l’application : elle affiche toujours sa version dans Réglages → Application.
