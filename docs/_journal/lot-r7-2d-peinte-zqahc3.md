Archipéo, lot R7 : la vue 2D peinte. Rien ne change pour l’élève : tout se passe derrière le drapeau de développement `?rendu=archipeo`. La vue 2D garde ses cases et ses gestes, mais quitte le pixel art pour les couleurs de la palette d’Archipéo, les mêmes qu’en 3D : sols en aplats nuancés, falaises en dégradé, sols voisins qui se mordent en festons, écume claire le long des rives, mer plus claire près des côtes, décor repeint sans changer de forme. La nuit n’est plus un voile sombre : la 2D prend les couleurs de nuit de chaque archipel, un bleu de crépuscule. Les captures de `npm run rendu:mesures -- --captures` montrent aussi la 2D de nuit et la vue de l’archipel en 2D.
