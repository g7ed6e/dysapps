**L’appli s’ouvre sur le village.**

- Après l’écran titre, **Jouer** mène directement au village de Blocland, sur l’île où se tient ton bonhomme. **Continuer** ramène toujours à la dernière quête.
- Dans le village, le bouton **Menu** (⏸, en haut à droite) ouvre le menu du jeu sans quitter le monde : Reprendre, Continuer, les révisions du jour, l’école, les quêtes, les succès, les réglages et l’aide.
- Le menu d’avant reste là, à l’onglet **Menu** (l’ancien onglet Accueil). Le nouveau réglage **Au démarrage** permet de rouvrir l’appli sur le menu plutôt que sur le village.
