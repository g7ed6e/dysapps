**Le jeu s’appelle Archipéo.** L’écran titre dit « Archipéo » et « Le savoir construit ton monde. » ; l’application installée prend ce nom, et Réglages → Application dit « Archipéo, par DysApps ».

- Les quêtes s’appellent maintenant des **missions**, partout : sur les îles, dans le menu, dans les bilans et dans les succès. Les adresses ne changent pas : un lien vers une mission marche toujours.
- Trois archipels prennent leur nom d’Archipéo : les **Premiers Rivages** (6e, anciennement les Basses Terres), les **Îles Brumeuses** (5e, les Collines du Large) et les **Anciens Ateliers** (4e, les Monts de Feu). Les Îles du Ciel (3e) gardent leur nom jusqu’à ce que l’archipel redescende sur la mer.
- Chaque matière est une **expédition** : Archives et récits (français), Mécanismes et énigmes (maths), Cartes et messages (anglais).
- Le réglage « Vue de Blocland » devient « Vue du monde ».

Rien ne se perd : la progression, les blocs, les étoiles et les constructions restent les mêmes.
