**La salle des trophées ouvre dans le village.**

- Sur la Forêt des sons (et sur l’île de l’école de chaque archipel), à côté de l’école, un pavillon de marbre : **chaque succès gagné y pose un trophée**. Or pour les exploits, cristal pour les rangs, quartz pour les Gardiens, lentille pour les voyages du Bloc-Navire. La salle se remplit à mesure qu’on joue.
- La toucher ouvre son panneau : ton rang, tes chiffres, tes étoiles par matière, ce qui est à retravailler et tous les succès. « Succès » dans le menu du village y mène aussi ; la page Succès reste là, hors du village.
