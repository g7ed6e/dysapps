# Le rendu

Le style commun et le rendu du monde. Tenu par l’artiste technique 3D pour la technique, sous l’intention du directeur artistique. Non publié.

- [Le style](style.md) : repères visuels, thèmes, polices, créatures, sons, célébrations.
- Le rendu propre à chaque univers : le [cadrage d’Archipéo](../univers/archipeo/cadrage.md) (plan des lots R), ses [intentions](../univers/archipeo/intentions/README.md) et sa [direction artistique](../univers/archipeo/source/direction-artistique.md) (figée) ; la [fiche de Blocland](../univers/blocland/fiche.md).
- Le budget de dessin reste dans le code : `src/game/world/budget.ts` (`npm run rendu:budget`).
- La règle des couches du code (jeu, monde, rendu) : [separation-jeu-rendu.md](../conception/separation-jeu-rendu.md).
