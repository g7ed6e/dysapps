### Niveau 1 · `french-5e-conjugation-past-tenses-1`

- consigne : Choisis le verbe au bon temps du passé : imparfait ou passé composé. La règle est affichée.

Pour tous les items :
- aide « Imparfait ou passé composé ? » :
  - Imparfait : description, habitude, action longue (il pleuvait, tous les jours je jouais).
  - Passé composé : action courte et finie, événement (soudain, il est tombé).
  - Terminaisons de l’imparfait : -ais, -ais, -ait, -ions, -iez, -aient.

1. énoncé : Tous les soirs, papa … une histoire.
   - choix : lisait · a lu · lira
   - réponse : lisait
   - indice : Tous les soirs = habitude : imparfait.
   - explication : Habitude (tous les soirs) : imparfait, « lisait ».
2. énoncé : Soudain, la porte … .
   - choix : claquait · a claqué · claque
   - réponse : a claqué
   - indice : Soudain = action courte et finie : passé composé.
   - explication : Événement soudain : passé composé, « a claqué ».
3. énoncé : Il … beau quand nous sommes partis.
   - choix : faisait · a fait · fera
   - réponse : faisait
   - indice : Description du temps qu’il fait : imparfait.
   - explication : Description (le temps) : imparfait, « faisait ».
4. énoncé : Hier, tu … ton devoir en une heure.
   - choix : finissais · as fini · finiras
   - réponse : as fini
   - indice : Hier, action finie une fois : passé composé.
   - explication : Action achevée : passé composé, « as fini ».
5. énoncé : Quand j’étais petit, je … peur du noir.
   - choix : avais · ai eu · aurai
   - réponse : avais
   - indice : Quand j’étais petit = état qui dure : imparfait.
   - explication : État durable dans le passé : imparfait, « avais ».
6. énoncé : Nous … au cinéma samedi dernier.
   - choix : allions · sommes allés · irons
   - réponse : sommes allés
   - indice : Samedi dernier, une sortie précise : passé composé.
   - explication : Événement précis : passé composé, « sommes allés ».
7. énoncé : Les enfants … pendant que je cuisinais.
   - choix : jouaient · ont joué · jouent
   - réponse : jouaient
   - indice : « Pendant que » : deux actions en même temps, longues : imparfait.
   - explication : Action longue en arrière-plan : imparfait, « jouaient ».
8. énoncé : Tout à coup, elle … le bruit.
   - choix : entendait · a entendu · entend
   - réponse : a entendu
   - indice : Tout à coup = action brève : passé composé.
   - explication : Action brève et soudaine : passé composé, « a entendu ».

### Niveau 2 · `french-5e-conjugation-past-tenses-2`

- consigne : Choisis le verbe au passé simple, le temps du récit écrit. La règle est affichée.

Pour tous les items :
- aide « Passé simple » :
  - Récit écrit, actions qui se suivent : il marcha, elle prit, ils virent.
  - Verbes en -er : -a, -èrent (il chanta, ils chantèrent).
  - Autres verbes : -it, -irent (il finit, ils prirent) ; -ut, -urent (il courut, ils eurent).

1. énoncé : Le chevalier … son épée et … .
   - lu : Le chevalier  (mot manquant)  son épée et  (mot manquant)  .
   - choix : prit / partit · prenait / partait · a pris / est parti
   - réponse : prit / partit
   - indice : Récit écrit, actions qui se suivent : passé simple.
   - explication : Actions successives d’un récit : passé simple, « prit », « partit ».
2. énoncé : Elle … la porte sans bruit.
   - choix : ouvrit · ouvrait · ouvre
   - réponse : ouvrit
   - indice : Passé simple des verbes en -ir : -it.
   - explication : « ouvrit » : passé simple, action brève du récit.
3. énoncé : Ils … toute la nuit.
   - choix : marchèrent · marchaient · marchent
   - réponse : marchèrent
   - indice : Verbe en -er, ils : -èrent.
   - explication : « marchèrent » : passé simple, terminaison -èrent.
4. énoncé : Le dragon … sur la tour.
   - choix : s’envola · s’envolait · s’envole
   - réponse : s’envola
   - indice : Verbe en -er, il : -a.
   - explication : « s’envola » : passé simple, terminaison -a.
5. énoncé : Il … vers la rivière.
   - choix : courut · courait · court
   - réponse : courut
   - indice : Courir, il : -ut.
   - explication : « courut » : passé simple, terminaison -ut.
6. énoncé : Au matin, les chevaliers … la route.
   - choix : prirent · prenaient · prennent
   - réponse : prirent
   - indice : Prendre, ils : -irent.
   - explication : « prirent » : passé simple, terminaison -irent.
7. énoncé : Nous … la cabane en un jour.
   - choix : construisîmes · construisions · construisons
   - réponse : construisîmes
   - indice : Passé simple, nous : -îmes.
   - explication : « construisîmes » : passé simple avec nous, terminaison -îmes.
8. énoncé : Soudain, ils … un cri.
   - choix : entendirent · entendaient · entendent
   - réponse : entendirent
   - indice : Ils, verbe en -re : -irent.
   - explication : « entendirent » : passé simple, terminaison -irent.

### Niveau 1 · `french-5e-conjugation-future-tense-1`

- consigne : Futur ou conditionnel ? Choisis le verbe qui convient. La règle est affichée.

Pour tous les items :
- aide « Futur ou conditionnel ? » :
  - Futur : ce qui arrivera, c’est sûr : je mangerai, tu viendras.
  - Conditionnel : à condition, poli, imaginé : je mangerais si j’avais faim ; je voudrais.
  - Astuce : avec « nous », le futur fait -rons et le conditionnel -rions.

1. énoncé : Demain, je … à la piscine.
   - choix : irai · irais · allais
   - réponse : irai
   - indice : Demain, c’est sûr : futur.
   - explication : Action certaine dans l’avenir : futur, « irai ».
2. énoncé : Si j’avais le temps, je … à la piscine.
   - choix : irai · irais · allais
   - réponse : irais
   - indice : « Si j’avais » : condition, conditionnel.
   - explication : Condition non réalisée : conditionnel, « irais ».
3. énoncé : Je … un verre d’eau, s’il vous plaît.
   - choix : voudrai · voudrais · voulais
   - réponse : voudrais
   - indice : Demande polie : conditionnel.
   - explication : Politesse : conditionnel, « voudrais ».
4. énoncé : L’année prochaine, nous … en 4e.
   - choix : serons · serions · étions
   - réponse : serons
   - indice : Avenir certain avec nous : -rons.
   - explication : Futur avec nous : « serons ».
5. énoncé : Avec des ailes, nous … .
   - choix : volerons · volerions · volions
   - réponse : volerions
   - indice : Imaginé, à condition d’avoir des ailes : conditionnel, -rions.
   - explication : Situation imaginée : conditionnel, « volerions ».
6. énoncé : Tu … tes devoirs ce soir.
   - choix : feras · ferais · faisais
   - réponse : feras
   - indice : Ordre pour ce soir, certain : futur.
   - explication : Action certaine : futur, « feras ».
7. énoncé : Il … content si tu venais.
   - choix : sera · serait · était
   - réponse : serait
   - indice : « si tu venais » : conditionnel.
   - explication : Condition : conditionnel, « serait ».
8. énoncé : Quand tu … grand, tu comprendras.
   - choix : seras · serais · étais
   - réponse : seras
   - indice : Après « quand » avec un futur : futur.
   - explication : Futur, « seras » : quand tu seras grand, tu comprendras.

### Niveau 2 · `french-5e-conjugation-future-tense-2`

- consigne : Conjugue au futur : choisis la bonne forme. La règle est affichée.

Pour tous les items :
- aide « Le futur » :

  - Terminaisons : -ai, -as, -a, -ons, -ez, -ont.
  - Verbes irréguliers : être → serai, avoir → aurai, aller → irai, faire → ferai, voir → verrai, venir → viendrai.

| Ils … le film ce soir. | verront · verrons · voiront | verront | Voir → verr-, ils : -ont. | Futur de voir avec ils : « verront ». |
| Tu … ta chambre. | rangeras · rangera · rangerai | rangeras | Tu : -as. | Futur avec tu : « rangeras ». |
| J’… douze ans en mai. | aurai · aurais · aurez | aurai | Avoir → aur-, je : -ai. | Futur d’avoir avec je : « aurai ». |
| Vous … les résultats lundi. | recevrez · recevez · receverez | recevrez | Recevoir → recevr-, vous : -ez. | Futur de recevoir avec vous : « recevrez ». |

### Niveau 1 · `french-5e-conjugation-tense-choice-1`

- consigne : Présent ou impératif : choisis la bonne forme du verbe. La règle est affichée.

Pour tous les items :
- trou lu : (mot manquant)
- aide « Le présent et l’impératif » :
  - Présent, verbes en -er : je -e, tu -es, il -e, nous -ons, vous -ez, ils -ent (tu joues).
  - Présent, autres verbes : souvent je -s, tu -s, il -t (je finis, il finit).
  - Impératif : un ordre, sans sujet écrit ; la forme du présent de tu, nous ou vous (Finis !).
  - À l’impératif, verbes en -er et aller : pas de s avec tu (Joue !).

1. énoncé : Tu … ton sac tous les soirs.
   - choix : ranges · range · rangent
   - réponse : ranges
   - indice : Le sujet est tu : quelle terminaison prend un verbe en -er avec tu ?
   - explication : Au présent, avec tu, un verbe en -er finit par -es : tu ranges. « Rangent » va avec ils.
2. énoncé : Nous … le bus à huit heures.
   - choix : prenons · prenez · prennent
   - réponse : prenons
   - indice : Qui prend le bus ? Cherche la terminaison qui va avec ce sujet.
   - explication : Avec nous, le présent finit par -ons : nous prenons. « Prenez » va avec vous, « prennent » avec ils.
3. énoncé : Vous … vos devoirs avant le dîner.
   - choix : faites · faisez · font
   - réponse : faites
   - indice : Faire se conjugue comme dire avec vous : vous dites.
   - explication : Faire est irrégulier : vous faites, comme vous dites et vous êtes. « Font » va avec ils.
4. énoncé : Mon frère … toujours merci.
   - choix : dit · dis · disent
   - réponse : dit
   - indice : Mon frère, c’est il. Quelle lettre finale avec il ?
   - explication : Avec il ou elle, dire finit par -t : il dit. « Dis » va avec je ou tu, « disent » avec ils.
5. énoncé : Léo, … ton manteau, il fait froid !
   - choix : mets · met · mettre
   - réponse : mets
   - indice : C’est un ordre donné à Léo : pense à tu, sans l’écrire.
   - explication : Impératif avec tu : on prend le présent, tu mets, sans le sujet. Mettre n’est pas un verbe en -er : il garde son s. Mets ton manteau !
6. énoncé : Inès, … chercher le pain, s’il te plaît.
   - choix : va · vas · vais
   - réponse : va
   - indice : Relis la règle de l’impératif, pour aller.
   - explication : Impératif avec tu : aller n’a pas de s, comme les verbes en -er. Va chercher le pain ! « Vais » s’emploie avec je.
7. énoncé : Les enfants, … vos mains !
   - choix : lavez · lavé · laver
   - réponse : lavez
   - indice : On parle à plusieurs enfants : à quelle personne ?
   - explication : Un ordre à plusieurs personnes : impératif avec vous, terminaison -ez. Lavez vos mains ! « Lavé » est un participe, « laver » un infinitif.
8. énoncé : Toi et moi, … vite à la maison !
   - choix : rentrons · rentrez · rentrer
   - réponse : rentrons
   - indice : Toi et moi : quel pronom peut les remplacer ?
   - explication : Toi et moi, c’est nous : impératif avec nous, terminaison -ons. Rentrons vite ! « Rentrez » s’adresse aux autres, sans moi.

### Niveau 2 · `french-5e-conjugation-tense-choice-2`

- consigne : Choisis le verbe au temps demandé : plus-que-parfait ou futur antérieur. La règle est affichée.

Pour tous les items :
- trou lu : (mot manquant)
- aide « Les temps composés » :
  - Temps composé : avoir ou être, puis le participe passé.
  - Plus-que-parfait : l’auxiliaire à l’imparfait (tu avais lu, ils étaient partis).
  - Futur antérieur : l’auxiliaire au futur (il aura lu, nous serons partis).
  - Avec être, le participe s’accorde avec le sujet (elle est partie, elles sont parties).

1. énoncé : Au plus-que-parfait : nous … nos exercices avant la récré.
   - choix : avions fini · avons fini · aurons fini
   - réponse : avions fini
   - indice : Au plus-que-parfait, à quel temps est l’auxiliaire ? Regarde la règle.
   - explication : Plus-que-parfait : avoir à l’imparfait, puis le participe : nous avions fini. « Avons fini » est le passé composé, « aurons fini » le futur antérieur.
2. énoncé : Au futur antérieur : demain à midi, j’… mon exposé.
   - lu : Au futur antérieur : demain à midi, je (mot manquant) mon exposé.
   - choix : aurai terminé · ai terminé · avais terminé
   - réponse : aurai terminé
   - indice : Quel est le futur du verbe avoir avec je ?
   - explication : Futur antérieur : avoir au futur, puis le participe : j’aurai terminé. « Ai terminé » est le passé composé, « avais terminé » le plus-que-parfait.
3. énoncé : Au plus-que-parfait : Léa … avant nous.
   - choix : était arrivée · avait arrivé · sera arrivée
   - réponse : était arrivée
   - indice : Au passé composé, dit-on elle a arrivé ou elle est arrivée ?
   - explication : Arriver se conjugue avec être : être à l’imparfait, puis le participe accordé avec Léa : elle était arrivée.
4. énoncé : Au futur antérieur : ils … avant la nuit.
   - choix : seront rentrés · auront rentré · étaient rentrés
   - réponse : seront rentrés
   - indice : Au passé composé, dit-on ils ont rentré ou ils sont rentrés ?
   - explication : Rentrer, revenir chez soi, se conjugue avec être : être au futur, puis le participe accordé avec ils : ils seront rentrés.
5. énoncé : Au plus-que-parfait : mes cousines … au cinéma.
   - choix : étaient allées · étaient allé · avaient allé
   - réponse : étaient allées
   - indice : Aller se conjugue avec être. Qui est le sujet, et combien sont-elles ?
   - explication : Aller se conjugue avec être : le participe s’accorde avec mes cousines, au féminin pluriel : elles étaient allées.
6. énoncé : Au futur antérieur : quand tu … ton goûter, tu pourras jouer.
   - choix : auras mangé · mangeras · avais mangé
   - réponse : auras mangé
   - indice : Quel est le futur du verbe avoir avec tu ?
   - explication : Futur antérieur : avoir au futur, puis le participe : tu auras mangé. « Mangeras » est le futur simple, sans auxiliaire ; « avais mangé », le plus-que-parfait.
7. énoncé : Au plus-que-parfait : il … son parapluie.
   - choix : avait pris · avait prit · aura pris
   - réponse : avait pris
   - indice : Pour trouver la dernière lettre du participe, dis-le au féminin.
   - explication : Le participe de prendre finit par s : pris, au féminin prise. « Prit », avec un t, c’est le passé simple : il prit.

   - explication : Le participe d’écrire finit par t : écrit, au féminin écrite. Futur antérieur : avoir au futur, vous aurez écrit.

### Niveau 3 · `french-5e-conjugation-tense-choice-3`

- consigne : Lis la phrase : que dit le temps du verbe, ou quelle action a lieu en premier ? La règle est affichée.

Pour tous les items :
- aide « Ce que dit le temps » :
  - Présent : ce qui se passe maintenant, une habitude, ou ce qui est toujours vrai.
  - Imparfait : le décor (ce qu’on décrit), ou une habitude du passé.
  - Passé simple : une action du récit, qui fait avancer l’histoire.
  - Plus-que-parfait et futur antérieur : l’action a lieu avant une autre.

1. énoncé : « Un triangle a trois côtés. » Que dit ce présent ?
   - lu : Un triangle a trois côtés. Que dit ce présent ?
   - choix : toujours vrai · maintenant · habitude
   - réponse : toujours vrai
   - indice : Est-ce vrai seulement aujourd’hui ?
   - explication : Un triangle a trois côtés hier, aujourd’hui et demain : c’est toujours vrai. On l’appelle le présent de vérité générale.
2. énoncé : « Chut, le bébé dort ! » Que dit ce présent ?
   - lu : Chut, le bébé dort ! Que dit ce présent ?
   - choix : maintenant · habitude · toujours vrai
   - réponse : maintenant
   - indice : Pourquoi dit-on « chut » ?
   - explication : Le bébé dort au moment où l’on parle : c’est ce qui se passe maintenant.
3. énoncé : « Le mercredi, je vais au judo. » Que dit ce présent ?
   - lu : Le mercredi, je vais au judo. Que dit ce présent ?
   - choix : habitude · toujours vrai · maintenant
   - réponse : habitude
   - indice : « Le mercredi » : une seule fois, ou chaque semaine ?
   - explication : « Le mercredi » veut dire chaque mercredi : l’action se répète, c’est une habitude. Ce n’est pas vrai pour tout le monde.
4. énoncé : « Il faisait nuit. Soudain, un chien aboya. » Que dit le verbe « aboya » ?
   - lu : Il faisait nuit. Soudain, un chien aboya. Que dit le verbe aboya ?
   - choix : action du récit · décor · habitude
   - réponse : action du récit
   - indice : Que veut dire « soudain » ?
   - explication : « Aboya » est au passé simple, après « soudain » : une action qui fait avancer le récit. « Il faisait nuit », c’est le décor.
5. énoncé : « La cour était vide, le vent soufflait. » Que dit le verbe « soufflait » ?
   - lu : La cour était vide, le vent soufflait. Que dit le verbe soufflait ?
   - choix : décor · action du récit · habitude
   - réponse : décor
   - indice : Se passe-t-il quelque chose de nouveau, ou décrit-on le lieu ?
   - explication : « Soufflait » est à l’imparfait : il décrit le lieu, rien n’avance encore. C’est le décor.
6. énoncé : « Chaque été, nous allions à la mer. » Que dit le verbe « allions » ?
   - lu : Chaque été, nous allions à la mer. Que dit le verbe allions ?
   - choix : habitude · décor · action du récit
   - réponse : habitude
   - indice : Que veut dire « chaque été » ?
   - explication : « Chaque été » : l’action se répète. L’imparfait dit ici une habitude du passé.
7. énoncé : « Tom souriait : il avait gagné le match. » Quelle action a lieu en premier ?
   - lu : Tom souriait : il avait gagné le match. Quelle action a lieu en premier ?
   - choix : il avait gagné le match · Tom souriait
   - réponse : il avait gagné le match
   - indice : Lequel des deux verbes est au plus-que-parfait ?
   - explication : « Avait gagné » est au plus-que-parfait : Tom a d’abord gagné, puis il souriait. L’ordre des mots n’est pas l’ordre des actions.
8. énoncé : « Je sortirai quand j’aurai fini mes devoirs. » Quelle action a lieu en premier ?
   - lu : Je sortirai quand j’aurai fini mes devoirs. Quelle action a lieu en premier ?
   - choix : j’aurai fini mes devoirs · je sortirai
   - réponse : j’aurai fini mes devoirs
   - indice : Lequel des deux verbes est au futur antérieur ?
   - explication : « Aurai fini » est au futur antérieur : les devoirs seront finis avant la sortie. La phrase dit « je sortirai » en premier, mais cette action a lieu après.
