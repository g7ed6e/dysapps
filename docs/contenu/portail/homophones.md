# Homophones

## a / à · `a`

- niveau : 1
- choix : a · à
- indice : Remplace par « avait ». Si ça marche, c’est « a » sans accent.
- règle « a » : « a » = verbe avoir : on peut dire « avait ».
- règle « à » : « à » est une préposition : on ne peut pas dire « avait ».

| phrase | réponse |
| --- | --- |
| Lina … raté son bus ce matin. | a |
| On se retrouve … la cantine. | à |
| Mon frère … gagné le tournoi de foot. | a |
| Je vais … la piscine avec Sami. | à |
| Le prof … oublié ses clés. | a |
| Elle joue … la console tous les soirs. | à |
| Il … un nouveau skate. | a |
| Le match commence … 18 heures. | à |

## et / est · `et`

- niveau : 1
- choix : et · est
- indice : Remplace par « était ». Si ça marche, c’est « est ».
- règle « est » : « est » = verbe être : on peut dire « était ».
- règle « et » : « et » relie deux mots ou deux idées : on peut dire « et puis ».

| phrase | réponse |
| --- | --- |
| Le film … trop long. | est |
| J’ai pris un sandwich … une pomme. | et |
| Ma sœur … en 3e. | est |
| Il pleut … il fait froid. | et |
| Ce jeu … vraiment difficile. | est |
| Nora … Hugo font leurs devoirs ensemble. | et |
| La salle de sport … fermée aujourd’hui. | est |
| Il a couru vite … il a gagné. | et |

## son / sont · `son`

- niveau : 1
- choix : son · sont
- indice : Remplace par « étaient ». Si ça marche, c’est « sont ».
- règle « sont » : « sont » = verbe être : on peut dire « étaient ».
- règle « son » : « son » = le sien, la sienne : on peut dire « mon ».

| phrase | réponse |
| --- | --- |
| Les résultats … affichés dans le hall. | sont |
| Tom a perdu … téléphone. | son |
| Mes amis … partis sans moi. | sont |
| Elle range … sac de sport. | son |
| Ces exercices … faciles. | sont |
| Il écoute … groupe préféré. | son |
| Les élèves … en sortie au musée. | sont |
| Adam prête … vélo à Léo. | son |

## on / ont · `on`

- niveau : 1
- choix : on · ont
- indice : Remplace par « avaient ». Si ça marche, c’est « ont ».
- règle « ont » : « ont » = verbe avoir : on peut dire « avaient ».
- règle « on » : « on » est un pronom sujet : on peut dire « il ».

| phrase | réponse |
| --- | --- |
| Mes cousins … adopté un chien. | ont |
| Ce soir, … regarde le match. | on |
| Les joueurs … marqué deux buts. | ont |
| Demain, … part en vacances. | on |
| Elles … fini leur projet en avance. | ont |
| Si … s’entraîne, on progresse. | on |
| Mes parents … changé de voiture. | ont |
| À la récré, … joue au basket. | on |

## ces / ses · `ces`

- niveau : 2
- choix : ces · ses
- indice : « ses » = les siens, les siennes. « ces » montre quelque chose : on peut ajouter « -là ».
- règle « ses » : « ses » = les siens, les siennes : c’est à lui ou à elle.
- règle « ces » : « ces » montre quelque chose : on peut ajouter « -là » après le nom (ces nuages-là).

| phrase | réponse |
| --- | --- |
| Lucas cherche … écouteurs partout. | ses |
| Regarde … nuages, il va pleuvoir. | ces |
| Elle a invité tous … amis. | ses |
| À qui sont … chaussures-là ? | ces |
| Il n’a pas fait … devoirs. | ses |
| J’adore … vidéos-là : elles sont drôles. | ces |
| Maya range … cahiers dans son casier. | ses |
| Je suis fatigué … jours-ci. | ces |

## ou / où · `ou`

- niveau : 2
- choix : ou · où
- indice : Remplace par « ou bien ». Si ça marche, c’est « ou » sans accent.
- règle « ou » : « ou » indique un choix : on peut dire « ou bien ».
- règle « où » : « où » indique un lieu ou un moment.

| phrase | réponse |
| --- | --- |
| Tu préfères la pizza … les pâtes ? | ou |
| Je ne sais pas … j’ai mis mes clés. | où |
| On y va à pied … à vélo ? | ou |
| C’est la ville … je suis né. | où |
| Tu viens samedi … dimanche ? | ou |
| Le jour … il a neigé, le collège était fermé. | où |
| Rouge … bleu, choisis vite. | ou |
| Dis-moi … tu habites. | où |

## ce / se · `ce`

- niveau : 2
- choix : ce · se
- indice : Essaie avec « je me » ou « tu te ». Si ça marche, c’est « se ».
- règle « se » : « se » va avec un verbe : on peut dire « je me lève », « tu te lèves ».
- règle « ce » : « ce » accompagne un nom ou veut dire « cela ».

| phrase | réponse |
| --- | --- |
| Il … lève tôt le lundi. | se |
| J’ai adoré … film. | ce |
| Elle … prépare pour le cross. | se |
| Tu as compris … que j’ai dit ? | ce |
| Les joueurs … serrent la main. | se |
| Je ne connais pas … jeu. | ce |
| Léa … souvient de tout. | se |
| Il faisait froid … matin. | ce |

## la / là / l’a · `la`

- niveau : 2
- choix : la · là · l’a
- indice : « l’a » = « l’avait ». « là » = un lieu, on peut dire « ici ». Sinon, c’est « la ».
- règle « l’a » : « l’a » : on peut dire « l’avait ».
- règle « là » : « là » indique un lieu : on peut dire « ici ».
- règle « la » : « la » accompagne un nom ou remplace un nom féminin.

| phrase | réponse |
| --- | --- |
| Pose ton sac …, près de la porte. | là |
| Sa casquette, il … oubliée dans le bus. | l’a |
| Ferme … fenêtre, s’il te plaît. | la |
| Ce film, elle … déjà vu deux fois. | l’a |
| Je t’attends …, devant le gymnase. | là |
| Passe-moi … balle ! | la |
| Sa trottinette, il … réparée tout seul. | l’a |
| Tu es … ? Je ne te vois pas. | là |

## leur / leurs · `leur`

- niveau : 3
- choix : leur · leurs
- indice : Devant un verbe, « leur » ne prend jamais de s. Devant un nom au pluriel, on écrit « leurs ».
- règle « leur » : « leur » devant un verbe (= à eux) ou devant un nom au singulier : pas de s.
- règle « leurs » : « leurs » devant un nom au pluriel : avec un s.

| phrase | réponse |
| --- | --- |
| Les élèves ont oublié … affaires. | leurs |
| Je … ai envoyé un message. | leur |
| Mes voisins promènent … chien. | leur |
| Ils ont rangé … chambres. | leurs |
| Le coach … explique la tactique. | leur |
| Elles ont retrouvé … amies. | leurs |
| Je … prête mon ballon. | leur |
| Ils attendent … résultats. | leurs |

## quand / quant / qu’en · `quand`

- niveau : 3
- choix : quand · quant · qu’en
- indice : « quand » = lorsque. « quant à » = en ce qui concerne. « qu’en » = que + en.
- règle « quand » : « quand » indique un moment : on peut dire « lorsque ».
- règle « quant » : « quant » s’emploie toujours avec « à », « au » ou « aux » : « en ce qui concerne ».
- règle « qu’en » : « qu’en » = « que » + « en ».

| phrase | réponse |
| --- | --- |
| Appelle-moi … tu arrives. | quand |
| Les autres partent ; … à moi, je reste. | quant |
| Je ne sais pas … penser. | qu’en |
| Il sourit … il gagne. | quand |
| On joue d’abord ; … aux devoirs, on verra demain. | quant |
| Il ne neige … hiver ici. | qu’en |
| Tu viendras … ? | quand |
| Elle ne voyage … train. | qu’en |

## peu / peut / peux · `peu`

- niveau : 3
- choix : peu · peut · peux
- indice : « peux » va avec je ou tu. « peut » va avec il, elle, on. « peu » = pas beaucoup.
- règle « peux » : « peux » : verbe pouvoir avec je ou tu.
- règle « peut » : « peut » : verbe pouvoir avec il, elle ou on (on peut dire « pouvait »).
- règle « peu » : « peu » = pas beaucoup.

| phrase | réponse |
| --- | --- |
| Tu … venir samedi ? | peux |
| Il … réussir s’il s’entraîne. | peut |
| J’ai très … dormi cette nuit. | peu |
| Je ne … pas sortir ce soir. | peux |
| On … commencer ? | peut |
| Il reste un … de gâteau. | peu |
| Elle … jouer du piano. | peut |
| Je … t’aider si tu veux. | peux |

## -é / -er · `er`

- niveau : 3
- choix : é · er
- indice : Remplace par « vendre » ou « vendu ». « vendre » → -er. « vendu » → -é.
- règle « é » : Participe passé : on peut dire « vendu », donc -é.
- règle « er » : Infinitif : on peut dire « vendre », donc -er.

| phrase | réponse |
| --- | --- |
| Il a mang… toute la pizza. | é |
| Je vais jou… au foot. | er |
| Elle a termin… son exposé. | é |
| Il faut rang… ta chambre. | er |
| Nous avons regard… un film. | é |
| Tu dois révis… ton contrôle. | er |
| Le match est annul…. | é |
| J’aime dessin… des mangas. | er |

## c’est / s’est · `cest`

- niveau : 3
- choix : c’est · s’est
- indice : « s’est » va avec un verbe comme « se lever » : il s’est levé, je me suis levé. « c’est » = « cela est ».
- règle « s’est » : « s’est » : verbe pronominal au passé composé (il s’est levé, je me suis levé).
- règle « c’est » : « c’est » = « cela est ».

| phrase | réponse |
| --- | --- |
| Il … blessé au genou. | s’est |
| Franchement, … mon jeu préféré. | c’est |
| Elle … inscrite au club de théâtre. | s’est |
| Tu sais, … facile. | c’est |
| Le chat … caché sous le lit. | s’est |
| Je crois que … fini. | c’est |
| Mon frère … trompé de salle. | s’est |
| Viens vite, … l’heure ! | c’est |
