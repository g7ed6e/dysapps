### Niveau 1 · `cabinet-racines-1`

- consigne : Retrouve le sens de la racine grecque ou latine. Les racines sont affichées.

Pour tous les items :
- aide « Racines grecques et latines » :
  - télé- = loin (téléphone, télévision).
  - -phone = son, voix. -graphe = écrire. -scope = regarder.
  - bio- = vie. géo- = terre. -logie = étude, science.
  - auto- = soi-même. poly- = plusieurs. micro- = petit.
  - thermo- = chaleur. -mètre = mesure. -gone = angle.

1. énoncé : Que signifie « télé- » dans télévision ?
   - lu : Que signifie « télé- » dans télévision ?
   - choix : loin · image · son
   - réponse : loin
   - indice : Télé-phone : la voix de loin.
   - explication : « télé- » = loin : la télévision montre des images de loin.
2. énoncé : Que signifie « bio- » dans biologie ?
   - lu : Que signifie « bio- » dans biologie ?
   - choix : vie · terre · eau
   - réponse : vie
   - indice : Bio-logie : l’étude de la vie.
   - explication : « bio- » = vie.
3. énoncé : Que signifie « -logie » dans géologie ?
   - lu : Que signifie « -logie » dans géologie ?
   - choix : étude · terre · mesure
   - réponse : étude
   - indice : -logie = science, étude.
   - explication : « -logie » = étude : la géologie est l’étude de la terre.
4. énoncé : Un « microscope » sert à …
   - choix : regarder le petit · mesurer le loin · écrire petit
   - réponse : regarder le petit
   - indice : micro- = petit, -scope = regarder.
   - explication : micro- (petit) + -scope (regarder).
5. énoncé : Un « autographe », c’est …
   - choix : une signature écrite de sa main · une photo de soi · un dessin automatique
   - réponse : une signature écrite de sa main
   - indice : auto- = soi-même, -graphe = écrire.
   - explication : auto- (soi-même) + -graphe (écrire) : une signature écrite de sa main.
6. énoncé : Un « polygone » a …
   - choix : plusieurs côtés · un seul côté · des côtés égaux
   - réponse : plusieurs côtés
   - indice : poly- = plusieurs, -gone = angle.
   - explication : poly- (plusieurs) + -gone (angle) : figure à plusieurs côtés.
7. énoncé : Que signifie « géo- » dans géographie ?
   - lu : Que signifie « géo- » dans géographie ?
   - choix : terre · eau · ciel
   - réponse : terre
   - indice : Géo-graphie : décrire la terre.
   - explication : « géo- » = terre.
8. énoncé : Un « thermomètre » mesure …
   - choix : la chaleur · le temps · la lumière
   - réponse : la chaleur
   - indice : thermo- = chaleur, -mètre = mesure.
   - explication : thermo- (chaleur) + -mètre (mesurer).

### Niveau 2 · `cabinet-racines-2`

- consigne : Préfixes et suffixes : forme le mot ou retrouve son sens. La liste est affichée.

Pour tous les items :
- aide « Préfixes et suffixes » :
  - in-, im-, il-, ir- = contraire (inutile, impossible, illisible, irrégulier).
  - re- = de nouveau (refaire). pré- = avant (préhistoire). anti- = contre (antivol).
  - -able = qui peut être (lavable). -eur = celui qui fait (chanteur). -tion = action (construction).

1. énoncé : Le contraire de « lisible » :
   - lu : Le contraire de « lisible » :
   - choix : illisible · inlisible · délisible
   - réponse : illisible
   - indice : Devant un l, in- devient il-.
   - explication : in- + lisible → « illisible » (le n devient l devant l).
2. énoncé : Le contraire de « possible » :
   - lu : Le contraire de « possible » :
   - choix : impossible · inpossible · dépossible
   - réponse : impossible
   - indice : Devant p ou b, in- devient im-.
   - explication : in- + possible → « impossible ».
3. énoncé : « Préhistoire » signifie …
   - choix : avant l’histoire · après l’histoire · contre l’histoire
   - réponse : avant l’histoire
   - indice : pré- = avant.
   - explication : pré- (avant) + histoire.
4. énoncé : Un objet « lavable » …
   - choix : peut être lavé · est déjà lavé · lave les autres
   - réponse : peut être lavé
   - indice : -able = qui peut être.
   - explication : -able = qui peut être : lavable = qui peut être lavé.
5. énoncé : « Refaire », c’est faire …
   - choix : de nouveau · contre · avant
   - réponse : de nouveau
   - indice : re- = de nouveau.
   - explication : re- = de nouveau : refaire = faire encore une fois.
6. énoncé : Un « antivol » sert à …
   - choix : empêcher le vol · voler · voler avant
   - réponse : empêcher le vol
   - indice : anti- = contre.
   - explication : anti- (contre) + vol.
7. énoncé : « Construction » est …
   - choix : l’action de construire · celui qui construit · ce qui peut être construit
   - réponse : l’action de construire
   - indice : -tion = action.
   - explication : -tion = action : construction = action de construire.
8. énoncé : Le contraire de « régulier » :
   - lu : Le contraire de « régulier » :
   - choix : irrégulier · inrégulier · dérégulier
   - réponse : irrégulier
   - indice : Devant un r, in- devient ir-.
   - explication : in- + régulier → « irrégulier ».

### Niveau 1 · `cabinet-sens-1`

- consigne : Sens propre ou sens figuré ? Demande-toi si c’est réel ou une image.

Pour tous les items :
- trou lu : " (mot manquant) "
- aide « Sens propre et sens figuré » :
  - Sens propre : le sens premier, concret (une pluie de gouttes).
  - Sens figuré : une image (une pluie de compliments).
  - Un mot peut avoir plusieurs sens : c’est la polysémie.

1. énoncé : « Une pluie de cadeaux » : quel sens ?
   - lu : « Une pluie de cadeaux » : quel sens ?
   - choix : figuré · propre
   - réponse : figuré
   - indice : Des cadeaux ne tombent pas vraiment du ciel : image.
   - explication : Image (beaucoup de cadeaux) : sens figuré.
2. énoncé : « Il pleut depuis ce matin » : quel sens ?
   - lu : « Il pleut depuis ce matin » : quel sens ?
   - choix : propre · figuré
   - réponse : propre
   - indice : De la vraie pluie : sens concret.
   - explication : Sens premier, concret : sens propre.
3. énoncé : « Avoir un cœur de pierre » signifie …
   - choix : être insensible · avoir mal au cœur · être fort
   - réponse : être insensible
   - indice : Sens figuré : dur comme la pierre.
   - explication : Image : un cœur dur, insensible.
4. énoncé : « Dévorer un livre » signifie …
   - choix : le lire avec passion · le manger · le déchirer
   - réponse : le lire avec passion
   - indice : On ne mange pas un livre : sens figuré.
   - explication : Sens figuré : lire vite et avec plaisir.
5. énoncé : « La bouche du métro » : quel sens ?
   - lu : « La bouche du métro » : quel sens ?
   - choix : figuré · propre
   - réponse : figuré
   - indice : Le métro n’a pas de vraie bouche : image de l’entrée.
   - explication : Image : l’entrée ressemble à une bouche, sens figuré.
6. énoncé : « Il a cassé un verre » : quel sens ?
   - lu : « Il a cassé un verre » : quel sens ?
   - choix : propre · figuré
   - réponse : propre
   - indice : On casse vraiment le verre.
   - explication : Action réelle et concrète : sens propre.
7. énoncé : « Tomber dans les pommes » signifie …
   - choix : s’évanouir · cueillir des pommes · faire une chute
   - réponse : s’évanouir
   - indice : Expression imagée.
   - explication : Sens figuré : perdre connaissance.
8. énoncé : « Le pied de la table » : quel sens ?
   - lu : « Le pied de la table » : quel sens ?
   - choix : figuré · propre
   - réponse : figuré
   - indice : La table n’a pas de vrai pied : image.
   - explication : Image (ce qui porte, comme un pied) : sens figuré.

### Niveau 2 · `cabinet-sens-2`

- consigne : Champ lexical : trouve le mot qui parle du thème. La règle est affichée.

Pour tous les items :
- aide « Champ lexical » :
  - Champ lexical : tous les mots qui parlent d’un même thème (la mer : vague, sable, marée).
  - Ce sont des noms, des verbes ou des adjectifs (nager, salé).
  - Pour trouver le thème, demande-toi de quoi parlent les mots.

1. énoncé : Quel mot appartient au champ lexical de la mer ?
   - lu : Quel mot appartient au champ lexical de la mer ?
   - choix : vague · sommet · prairie
   - réponse : vague
   - indice : Cherche ce qu’on voit depuis une plage.
   - explication : « vague » parle de la mer. « sommet » parle de la montagne, « prairie » de la campagne.
2. énoncé : Quel mot appartient au champ lexical de l’école ?
   - lu : Quel mot appartient au champ lexical de l’école ?
   - choix : cartable · valise · panier
   - réponse : cartable
   - indice : Cherche ce qu’on emporte en classe.
   - explication : « cartable » parle de l’école. On emporte une valise en voyage, un panier au marché.
3. énoncé : « tonnerre, éclair, averse » : quel est leur thème ?
   - lu : « tonnerre, éclair, averse » : quel est leur thème ?
   - choix : l’orage · la fête · la mer
   - réponse : l’orage
   - indice : Regarde les trois mots ensemble.
   - explication : Tonnerre, éclair et averse parlent de l’orage : c’est leur champ lexical.
4. énoncé : Quel mot appartient au champ lexical du pain ?
   - lu : Quel mot appartient au champ lexical du pain ?
   - choix : boulanger · boucher · fleuriste
   - réponse : boulanger
   - indice : Qui fait le pain ?
   - explication : « boulanger » parle du pain. Le boucher et le fleuriste sont aussi des commerçants, mais ne font pas de pain.
5. énoncé : Quel verbe appartient au champ lexical du sport ?
   - lu : Quel verbe appartient au champ lexical du sport ?
   - choix : courir · dessiner · chanter
   - réponse : courir
   - indice : Un champ lexical réunit aussi des verbes.
   - explication : « courir » parle du sport : un verbe peut faire partie d’un champ lexical.
6. énoncé : « trembler, cauchemar, terrifié » : quel est leur thème ?
   - lu : « trembler, cauchemar, terrifié » : quel est leur thème ?
   - choix : la peur · le sommeil · la colère
   - réponse : la peur
   - indice : Un seul mot ne suffit pas : regarde les trois.
   - explication : « cauchemar » fait penser au sommeil, mais les trois mots ensemble parlent de la peur.
7. énoncé : Quel adjectif appartient au champ lexical de l’hiver ?
   - lu : Quel adjectif appartient au champ lexical de l’hiver ?
   - choix : glacial · brûlant · fleuri
   - réponse : glacial
   - indice : Pense au froid.
   - explication : « glacial » parle du froid de l’hiver. « brûlant » parle de l’été, « fleuri » du printemps.
8. énoncé : Quel mot appartient au champ lexical du cinéma ?
   - lu : Quel mot appartient au champ lexical du cinéma ?
   - choix : film · roman · chanson
   - réponse : film
   - indice : Que regarde-t-on sur le grand écran ?
   - explication : « film » parle du cinéma. Un roman se lit, une chanson s’écoute.
