### Niveau 2 · `lca-3e-ideas-gr-heritage-2`

- aide « Racines grecques » :
  - anthrôpos : l’être humain ; philos : qui aime ; phobos : la peur.
  - hudôr : l’eau ; pur : le feu ; hippos : le cheval.
  - pous, podos : le pied ; odous, odontos : la dent ; kardia : le cœur.
  - monos : seul ; arkhê : le commandement ; kratos : le pouvoir.
  - anti- : contre ; sun-, en français syn- ou sym- : avec ; dia- : à travers.
  - Un mot savant assemble souvent deux racines : hippo- et -drome (la course), hippodrome.

   - réponse : sur l’eau
   - indice : Relis la deuxième ligne du rappel.
   - explication : Hudôr, l’eau : un hydravion décolle et se pose sur l’eau. Même racine : hydrater, déshydraté.
2. énoncé : Un « pyromane » est attiré par …
   - choix : les chevaux · le feu · l’eau
   - réponse : le feu
   - indice : Relis la deuxième ligne du rappel.
   - explication : Pur, puros, le feu : un pyromane allume des incendies ; la pyrotechnie fabrique les feux d’artifice.
3. énoncé : "Le mot hippopotame\nhippos : le cheval\npotamos : le fleuve"

   - lu : Le mot hippopotame. Hipposs : le cheval. Potamoss : le fleuve.
   - choix : le cheval du fleuve · le grand cheval · le fleuve des chevaux
   - réponse : le cheval du fleuve
   - indice : Est-ce un cheval, ou un fleuve ?
   - explication : Hippopotame veut dire « le cheval du fleuve » : les Grecs l’ont vu dans le Nil. C’est un animal, pas un fleuve.
4. énoncé : Au théâtre, quand un personnage parle seul, c’est un …
   - choix : dialogue · monologue · prologue
   - réponse : monologue
   - indice : Relis la quatrième ligne du rappel.
   - explication : Monos, seul, et logos, la parole : un monologue, c’est un personnage qui parle seul. Dans un dialogue (dia-, à travers, entre), on parle à deux ou plus.
5. énoncé : Un « philanthrope » est une personne qui …
   - choix : aime les êtres humains et les aide · a peur des autres · étudie les chevaux
   - réponse : aime les êtres humains et les aide
   - indice : Relis la première ligne du rappel.
   - explication : Philos (qui aime) et anthrôpos (l’être humain) : un philanthrope aime les êtres humains et les aide. Son contraire, le misanthrope, fuit les autres.
6. énoncé : Un « podologue » soigne …
   - choix : les dents · le cœur · les pieds
   - réponse : les pieds
   - indice : Relis la troisième ligne du rappel.
   - explication : Pous, podos, le pied : le podologue soigne les pieds. L’orthodontiste, lui, s’occupe des dents (odous, odontos) ; le cardiologue, du cœur.
7. énoncé : « Antipathie » : anti- et pathos, ce que l’on ressent. L’antipathie, c’est …
   - lu : Antipathie : anti, et patoss, ce que l’on ressent. L’antipathie, c’est (mot manquant)
   - choix : un sentiment partagé avec quelqu’un · un sentiment contre quelqu’un · de la pitié
   - réponse : un sentiment contre quelqu’un
   - indice : Relis l’avant-dernière ligne du rappel.
   - explication : Anti- veut dire contre : l’antipathie, c’est ce que l’on ressent contre quelqu’un. Son contraire, la sympathie (sym-, avec), c’est ressentir avec l’autre.
8. énoncé : Le mot « monarchie » veut dire …
   - choix : le pouvoir du peuple · le gouvernement des riches · le commandement d’un seul
   - réponse : le commandement d’un seul
   - indice : Relis la quatrième ligne du rappel.
   - explication : Monos (seul) et arkhê (le commandement) : la monarchie, c’est un seul qui commande, comme un roi. La démocratie, c’est le pouvoir du peuple.
