### Niveau 1 · `french-4e-agreement-past-participle-1`

- consigne : Accorde le participe passé : avec être, il suit le sujet ; avec avoir, il ne s’accorde pas avec le sujet. La règle est affichée.

Pour tous les items :
- aide « Participe passé avec être et avoir » :
  - Avec être : le participe s’accorde avec le sujet (elles sont parties).
  - Avec avoir : pas d’accord avec le sujet (elles ont mangé).
  - Astuce : remplace par « pris / prise » pour entendre le son.

1. énoncé : Les filles sont … à la piscine.
   - choix : allées · allé · allés
   - réponse : allées
   - indice : Avec être : accord avec le sujet « les filles » (féminin pluriel).
   - explication : Être + sujet féminin pluriel : « allées ».
2. énoncé : Ils ont … toute la pizza.
   - choix : mangé · mangés · mangée
   - réponse : mangé
   - indice : Avec avoir, pas d’accord avec le sujet.
   - explication : Avoir : le participe reste « mangé ».
3. énoncé : Ma sœur est … en retard.
   - choix : arrivée · arrivé · arrivés
   - réponse : arrivée
   - indice : Être + « ma sœur » (féminin singulier).
   - explication : Être + sujet féminin singulier : « arrivée ».
4. énoncé : Nous avons … un film.
   - choix : regardé · regardés · regardées
   - réponse : regardé
   - indice : Avec avoir, pas d’accord.
   - explication : Avoir : « regardé » ne change pas.
5. énoncé : Les garçons sont … tôt.
   - choix : partis · parti · parties
   - réponse : partis
   - indice : Être + « les garçons » (masculin pluriel).
   - explication : Être + sujet masculin pluriel : « partis ».
6. énoncé : Elle a … une lettre.
   - choix : écrit · écrite · écrits
   - réponse : écrit
   - indice : Avec avoir, pas d’accord avec « elle ».
   - explication : Avoir : « écrit » ne s’accorde pas avec le sujet.
7. énoncé : Les feuilles sont … .
   - choix : tombées · tombés · tombé
   - réponse : tombées
   - indice : Être + « les feuilles » (féminin pluriel).
   - explication : Être + sujet féminin pluriel : « tombées ».
8. énoncé : Vous avez … la bonne réponse.
   - choix : trouvé · trouvés · trouvée
   - réponse : trouvé
   - indice : Avec avoir, pas d’accord avec « vous ».
   - explication : Avoir : « trouvé » reste invariable.

### Niveau 2 · `french-4e-agreement-past-participle-2`

- consigne : Accorde le participe passé avec avoir : il s’accorde avec le complément d’objet direct placé avant. Pose la question « quoi ? ».

Pour tous les items :
- aide « Participe passé avec avoir et COD placé avant » :
  - Avec avoir, le participe s’accorde avec le COD seulement s’il est placé AVANT le verbe.
  - La lettre que j’ai écrite : « que » (= la lettre) est avant → accord.
  - J’ai écrit la lettre : le COD est après → pas d’accord.
  - Cherche « quoi ? » après le verbe.

1. énoncé : La lettre que j’ai … est partie.
   - choix : écrite · écrit · écrits
   - réponse : écrite
   - indice : J’ai écrit quoi ? « que » = la lettre, placé avant : accord.
   - explication : COD « que » (la lettre) avant le verbe : « écrite ».
2. énoncé : J’ai … la lettre ce matin.
   - choix : écrit · écrite · écrits
   - réponse : écrit
   - indice : J’ai écrit quoi ? la lettre, après le verbe : pas d’accord.
   - explication : COD après le verbe : « écrit ».
3. énoncé : Les pommes que tu as … sont mûres.
   - choix : cueillies · cueilli · cueillis
   - réponse : cueillies
   - indice : Tu as cueilli quoi ? « que » = les pommes, avant : accord féminin pluriel.
   - explication : COD avant le verbe, féminin pluriel : « cueillies ».
4. énoncé : Elle les a … hier.
   - choix : vus · vu · vue
   - réponse : vus
   - indice : Elle a vu qui ? « les » (eux), placé avant : accord masculin pluriel.
   - explication : COD « les » avant le verbe : « vus ».
5. énoncé : Ils ont … leurs amis.
   - choix : invité · invités · invitée
   - réponse : invité
   - indice : Ils ont invité qui ? leurs amis, après le verbe : pas d’accord.
   - explication : COD après le verbe : « invité ».
6. énoncé : Quelle chanson as-tu … ?
   - choix : choisie · choisi · choisis
   - réponse : choisie
   - indice : Tu as choisi quoi ? « quelle chanson », avant : accord féminin.
   - explication : COD « quelle chanson » avant le verbe : « choisie ».
7. énoncé : Les photos, je les ai … .
   - choix : vues · vu · vus
   - réponse : vues
   - indice : J’ai vu quoi ? « les » = les photos, avant : féminin pluriel.
   - explication : COD « les » (les photos) avant : « vues ».
8. énoncé : Nous avons … des cadeaux.
   - choix : reçu · reçus · reçue
   - réponse : reçu
   - indice : Nous avons reçu quoi ? des cadeaux, après : pas d’accord.
   - explication : COD après le verbe : « reçu ».

### Niveau 1 · `french-4e-agreement-subject-verb-1`

- consigne : Trouve le sujet avec « qui est-ce qui ? », puis accorde le verbe. La règle est affichée.

Pour tous les items :
- aide « Trouver le sujet » :
  - Le verbe s’accorde avec son sujet, même s’il est loin ou après le verbe.
  - Pose la question « qui est-ce qui ? » avant le verbe.
  - « on », « chacun », « tout le monde » : singulier. « la plupart des élèves » : pluriel.

1. énoncé : Les enfants de la voisine … dans le jardin.
   - choix : jouent · joue · jouons
   - réponse : jouent
   - indice : Qui est-ce qui joue ? les enfants → pluriel.
   - explication : Sujet « les enfants » (pluriel) : « jouent ».
2. énoncé : Dans la cour … deux chats.
   - choix : dorment · dort · dors
   - réponse : dorment
   - indice : Qui est-ce qui dort ? deux chats, placés après le verbe.
   - explication : Sujet inversé « deux chats » : « dorment ».
3. énoncé : On … demain matin.
   - choix : part · partent · pars
   - réponse : part
   - indice : « on » : toujours singulier.
   - explication : « on » = 3e personne du singulier : « part ».
4. énoncé : Tout le monde … la réponse.
   - choix : connaît · connaissent · connais
   - réponse : connaît
   - indice : « tout le monde » : singulier.
   - explication : « tout le monde » est singulier : « connaît ».
5. énoncé : Le sac de billes … lourd.
   - choix : est · sont · es
   - réponse : est
   - indice : Qui est-ce qui est lourd ? le sac, pas les billes.
   - explication : Sujet « le sac » (singulier) : « est ».
6. énoncé : La plupart des élèves … réussi.
   - choix : ont · a · as
   - réponse : ont
   - indice : « la plupart des élèves » : pluriel.
   - explication : « la plupart des élèves » se conjugue au pluriel : « ont ».
7. énoncé : Pierre et toi … en avance.
   - choix : êtes · sont · es
   - réponse : êtes
   - indice : Pierre et toi = vous.
   - explication : « Pierre et toi » = vous : « êtes ».
8. énoncé : Chacun … sa place.
   - choix : reprend · reprennent · reprends
   - réponse : reprend
   - indice : « chacun » : singulier.
   - explication : « chacun » est singulier : « reprend ».

   - indice : Qui est-ce qui aboie ? le chien.
   - explication : Sujet « le chien » (singulier) : « aboie ».
3. énoncé : Toi et moi … amis.
   - choix : sommes · êtes · sont
   - réponse : sommes
   - indice : Toi et moi = nous.

4. énoncé : Le vent et la pluie … la maison.

   - indice : Deux sujets reliés par « et » : pluriel.

5. énoncé : C’est toi qui … raison.
   - choix : as · a · ai
   - réponse : as
   - indice : « qui » = toi : 2e personne.
   - explication : « qui » reprend « toi » : « as ».
6. énoncé : Les résultats de l’enquête … demain.
   - choix : tombent · tombe · tombes
   - réponse : tombent
   - indice : Qui est-ce qui tombe ? les résultats.

### Niveau 1 · `french-4e-agreement-reflexive-verbs-1`

- consigne : Choisis la bonne forme du verbe pronominal. La règle est affichée.
- bravo : Bien conjugué !

Pour tous les items :
- aide « Les verbes pronominaux » :
  - Le pronom a la même personne que le sujet.
  - je me, tu te, il se, nous nous, vous vous, ils se.
  - Aux temps composés, toujours l’auxiliaire être (nous nous sommes trompés).
  - À l’impératif, le pronom passe après le verbe (lève-toi, levons-nous).
  - S’en aller : « en » reste collé au pronom (tu t’en vas, elle s’en est allée).

1. énoncé : Nous … souvenons de ce voyage.
   - choix : nous · se · vous
   - réponse : nous
   - indice : Qui se souvient ? Cherche le pronom de la même personne.
   - explication : Avec nous, le pronom est aussi nous : nous nous souvenons. « Se » va avec il ou ils, « vous » avec vous.
2. énoncé : Tu … méfies trop des chiens.
   - choix : te · se · me
   - réponse : te
   - indice : Relis la liste des pronoms : lequel va avec tu ?
   - explication : Avec tu, le pronom est te : tu te méfies. « Se » va avec il ou ils, « me » avec je.
3. énoncé : Vous … moquez toujours de moi !
   - choix : vous · se · nous
   - réponse : vous
   - indice : Qui se moque ? Cherche le pronom de la même personne.
   - explication : Avec vous, le pronom est aussi vous : vous vous moquez. On écrit deux fois vous : le sujet, puis le pronom.
4. énoncé : Hier, le chat … enfui par la fenêtre.
   - choix : s’est · s’a · a
   - réponse : s’est
   - indice : Aux temps composés, quel auxiliaire prend un verbe pronominal ?
   - explication : S’enfuir est pronominal : il se conjugue avec être, et garde son pronom. Le chat s’est enfui. Jamais avoir.
5. énoncé : Pendant l’orage, les oiseaux … envolés.
   - choix : se sont · s’ont · ont
   - réponse : se sont
   - indice : Quel est l’infinitif ? Et quel auxiliaire aux temps composés ?
   - explication : S’envoler est pronominal : l’auxiliaire être, et le pronom se. Les oiseaux se sont envolés. Jamais avoir.
6. énoncé : Léo, …, le bus arrive !
   - choix : dépêche-toi · te dépêche · dépêches-toi
   - réponse : dépêche-toi
   - indice : C’est un ordre : où se place le pronom ? Et avec tu, un verbe en -er prend-il un s ?
   - explication : À l’impératif, le pronom passe après le verbe, avec un trait d’union : dépêche-toi. Verbe en -er : pas de s avec tu.
7. énoncé : Il est tard : je … .
   - lu : Il est tard : je (mot manquant).
   - choix : m’en vais · m’en vas · m’en va
   - réponse : m’en vais
   - indice : S’en aller se conjugue comme aller : que dit-on avec je, au présent ?
   - explication : S’en aller se conjugue comme aller : je vais, donc je m’en vais. « Vas » va avec tu (tu t’en vas), « va » avec il (il s’en va).
8. énoncé : Après le goûter, les invités … .
   - lu : Après le goûter, les invités (mot manquant).
   - choix : s’en sont allés · se sont en allés · s’en ont allés
   - réponse : s’en sont allés
   - indice : Où se place « en » : avant ou après l’auxiliaire ? Et quel auxiliaire ?
   - explication : « En » reste collé au pronom, avant l’auxiliaire être : les invités s’en sont allés. On ne sépare pas « s’en ».

### Niveau 2 · `french-4e-agreement-reflexive-verbs-2`

- consigne : Accorde le participe passé du verbe pronominal. La règle est affichée.
- bravo : Bien accordé !

Pour tous les items :
- aide « Le participe passé des verbes pronominaux » :
  - Le plus souvent, le participe s’accorde avec le sujet : elles s’étaient assises.
  - Un COD placé après le verbe : pas d’accord (tu t’es coupé le doigt).
  - Verbe construit avec à (on sourit à quelqu’un, on téléphone à quelqu’un) : pas d’accord.

1. énoncé : Hier soir, mes sœurs se sont … tôt.
   - choix : couchées · couché · couchés
   - réponse : couchées
   - indice : Y a-t-il un COD après le verbe ? Sinon, cherche le sujet.
   - explication : Pas de COD après le verbe : le participe s’accorde avec le sujet, mes sœurs, au féminin pluriel. Elles se sont couchées.
2. énoncé : Léa s’est … les cheveux ce matin.
   - choix : lavé · lavée · lavés
   - réponse : lavé
   - indice : Léa lave quoi ? Regarde ce qui suit le verbe.
   - explication : Léa lave les cheveux : c’est un COD, placé après le verbe. Pas d’accord : Léa s’est lavé les cheveux.
3. énoncé : Les garçons se sont … dans la forêt.
   - choix : perdus · perdu · perdues
   - réponse : perdus
   - indice : Y a-t-il un COD après le verbe ? Sinon, cherche le sujet.
   - explication : Pas de COD après le verbe : accord avec le sujet, les garçons, au masculin pluriel. Ils se sont perdus.
4. énoncé : Mes cousines se sont … au téléphone pendant une heure.
   - choix : parlé · parlées · parlés
   - réponse : parlé
   - indice : Parle-t-on quelqu’un, ou parle-t-on à quelqu’un ?
   - explication : On parle à quelqu’un : « se » veut dire « l’une à l’autre », ce n’est pas un COD. Pas d’accord : elles se sont parlé.
5. énoncé : Ma grand-mère s’est … le poignet en tombant.
   - choix : cassé · cassée · cassés
   - réponse : cassé
   - indice : Regarde ce qui suit le verbe : y a-t-il un COD ?
   - explication : Le poignet est un COD, placé après le verbe : pas d’accord. Ma grand-mère s’est cassé le poignet.
6. énoncé : Avant le match, les deux équipes se sont … .
   - lu : Avant le match, les deux équipes se sont (mot manquant).
   - choix : saluées · salué · salués
   - réponse : saluées
   - indice : Salue-t-on quelqu’un, ou salue-t-on à quelqu’un ?
   - explication : On salue quelqu’un, sans à, et aucun COD ne suit le verbe : accord avec le sujet, les équipes, au féminin pluriel. Elles se sont saluées.
7. énoncé : Les enfants se sont … les dents.
   - choix : brossé · brossés · brossées
   - réponse : brossé

### Niveau 3 · `french-4e-agreement-reflexive-verbs-3`

- consigne : Trouve le groupe apposé ou le nom qu’il précise, ou choisis le bon accord. La règle est affichée.

Pour tous les items :
- aide « L’apposition » :

- bravo : Bien vu !
- erreur : {explanation}

- descend à : 0.5

### Niveau 1 · `french-4e-agreement-tense-meaning-1`

- consigne : Lis la phrase : que dit le temps ou le mode du verbe ? La règle est affichée.

Pour tous les items :
- aide « Ce que disent les temps et les modes » :
  - Temps simple : l’action se fait (je range). Temps composé : elle est finie (j’ai rangé).
  - Imparfait : l’action dure, c’est le décor. Passé simple : l’action vue en entier, qui fait avancer le récit.
  - Indicatif : un fait réel. Subjonctif : ce qu’on veut ou ce qu’il faut (je veux que tu viennes).
  - Conditionnel : un fait imaginé, ou une demande polie. Impératif : un ordre, un conseil.

1. énoncé : « Quand il a fini ses devoirs, Tom joue aux cartes. » Ses devoirs sont-ils finis quand il joue ?
   - lu : Quand il a fini ses devoirs, Tom joue aux cartes. Ses devoirs sont-ils finis quand il joue ?
   - choix : oui, ils sont finis · non, il les fait encore
   - réponse : oui, ils sont finis
   - indice : « A fini » : temps simple ou temps composé ? Relis la règle.
   - explication : « A fini » est un temps composé : l’action est finie avant que Tom joue. Avec un temps simple, « quand il finit ses devoirs », il serait encore en train de les faire.
2. énoncé : « Elle lisait une page quand le téléphone sonna. » Au moment où le téléphone sonne, que fait-elle ?
   - lu : Elle lisait une page quand le téléphone sonna. Au moment où le téléphone sonne, que fait-elle ?
   - choix : elle a fini sa page · elle est en train de lire
   - réponse : elle est en train de lire
   - indice : « Lisait » est à l’imparfait : l’action est-elle vue en entier, ou en train de durer ?
   - explication : L’imparfait montre l’action en train de durer : elle lisait encore quand le téléphone sonna. Rien ne dit qu’elle avait fini sa page.
3. énoncé : « Ce soir-là, elle lut une page, puis elle éteignit. » A-t-elle lu la page en entier ?
   - lu : Ce soir-là, elle lut une page, puis elle éteignit. A-t-elle lu la page en entier ?
   - choix : oui, en entier · non, elle s’est arrêtée au milieu
   - réponse : oui, en entier
   - indice : « Lut » est au passé simple : l’action est-elle vue en entier ?
   - explication : Le passé simple montre l’action en entier, du début à la fin : elle lut la page, puis elle éteignit. Les deux actions se suivent.
4. énoncé : « Le soleil se couchait, les oiseaux se taisaient ; alors Hugo ferma les volets. » Quel verbe fait avancer le récit ?
   - lu : Le soleil se couchait, les oiseaux se taisaient ; alors Hugo ferma les volets. Quel verbe fait avancer le récit ?
   - choix : se couchait · ferma · se taisaient
   - réponse : ferma
   - indice : Lequel des trois verbes est au passé simple ?
   - explication : « Ferma » est au passé simple : c’est l’action du récit, au premier plan. « Se couchait » et « se taisaient », à l’imparfait, posent le décor, à l’arrière-plan.
5. énoncé : « Je sais que tu viens. » Que dit le mode du verbe « viens » ?
   - lu : Je sais que tu viens. Que dit le mode du verbe « viens » ?
   - choix : une volonté · un fait réel · un fait imaginé
   - réponse : un fait réel
   - indice : Après « je sais que », le fait est-il sûr ?
   - explication : Après « je sais que », le verbe est à l’indicatif : il présente un fait réel, que l’on sait.
6. énoncé : « Je veux que tu viennes. » Que dit le mode du verbe « viennes » ?
   - lu : Je veux que tu viennes. Que dit le mode du verbe « viennes » ?
   - choix : un fait réel · un fait imaginé · une volonté
   - réponse : une volonté
   - indice : Après « je veux que », dit-on ce qui est, ou ce qu’on souhaite ?
   - explication : Après « je veux que », le verbe est au subjonctif : « viennes » dit ce que je veux, pas un fait réel. Tu n’es peut-être pas encore venu.
7. énoncé : « Avec un chien, nous ferions de longues promenades. » Que dit le conditionnel « ferions » ?
   - lu : Avec un chien, nous ferions de longues promenades. Que dit le conditionnel « ferions » ?
   - choix : un fait imaginé · un fait réel · un ordre
   - réponse : un fait imaginé
   - indice : Les promenades ont-elles lieu, ou dépendent-elles d’une condition ?
   - explication : Le conditionnel dit ce qui arriverait avec un chien : c’est un fait imaginé, qui dépend d’une condition. Un fait réel serait à l’indicatif : nous faisons de longues promenades.
8. énoncé : « Pourrais-tu m’aider à porter ce sac ? » Pourquoi le conditionnel ?
   - lu : Pourrais-tu m’aider à porter ce sac ? Pourquoi le conditionnel ?
   - choix : pour parler de demain · pour demander poliment · pour donner un ordre
   - réponse : pour demander poliment
   - indice : Compare avec « Peux-tu m’aider ? » : laquelle est la plus douce ?
   - explication : Le conditionnel adoucit la demande : « Pourrais-tu » est plus poli que « Peux-tu ». Ce n’est pas un futur : au futur, on dirait « pourras-tu », sans i.

### Niveau 2 · `french-4e-agreement-tense-meaning-2`

- consigne : Ponctuation : lis la phrase, puis réponds à la question. La règle est affichée.

Pour tous les items :
- aide « Les signes de ponctuation » :
  - Virgule : sépare les mots d’une liste, isole celui à qui l’on parle, encadre un groupe qu’on peut enlever.
  - Point-virgule : relie deux propositions proches par le sens. Après lui, pas de majuscule.
  - Deux-points : annoncent une liste, une explication ou des paroles.
  - Une relative entre virgules parle de tous ; sans virgules, elle trie : seulement certains.

1. énoncé : « J’ai rangé mes livres … mes cahiers et mes crayons. » Quel signe va à la place du trou ?
   - lu : J’ai rangé mes livres (signe manquant) mes cahiers et mes crayons. Quel signe va à la place du trou ?
   - choix : un point · une virgule · deux-points
   - réponse : une virgule
   - indice : Les livres, les cahiers et les crayons forment-ils une liste ?
   - explication : Livres, cahiers et crayons forment une liste : la virgule sépare les mots d’une liste, et « et » relie les deux derniers. Un point couperait la phrase en deux.
2. énoncé : « J’ai trois matières préférées : le dessin, l’anglais et le sport. » À quoi servent les deux-points ?
   - lu : J’ai trois matières préférées : le dessin, l’anglais et le sport. À quoi servent les deux-points ?
   - choix : annoncer une liste · annoncer une explication · annoncer des paroles
   - réponse : annoncer une liste
   - indice : Que vient-il après les deux-points ?
   - explication : Après les deux-points viennent les trois matières : les deux-points annoncent une liste. Personne ne parle, et rien n’est expliqué.
3. énoncé : « Tom reste au lit : il a de la fièvre. » À quoi servent les deux-points ?
   - lu : Tom reste au lit : il a de la fièvre. À quoi servent les deux-points ?
   - choix : annoncer des paroles · annoncer une liste · annoncer une explication
   - réponse : annoncer une explication
   - indice : La fin de la phrase dit-elle pourquoi Tom reste au lit ?
   - explication : « Il a de la fièvre » dit pourquoi Tom reste au lit : les deux-points annoncent une explication, ici une cause. Il n’y a ni liste, ni paroles.
4. énoncé : Léa crie : « Attends-moi ! » À quoi servent les deux-points ?
   - lu : Léa crie : Attends-moi ! À quoi servent les deux-points ?
   - choix : annoncer une explication · annoncer des paroles · annoncer une liste
   - réponse : annoncer des paroles
   - indice : Après les deux-points, qui parle ? Regarde les guillemets.
   - explication : Après « crie », les deux-points annoncent les mots exacts de Léa, entre guillemets : des paroles rapportées au discours direct.
5. énoncé : « Le jour se lève ; les oiseaux chantent déjà. » À quoi sert le point-virgule ?
   - lu : Le jour se lève ; les oiseaux chantent déjà. À quoi sert le point-virgule ?
   - choix : relier deux propositions proches · annoncer une liste · séparer deux phrases sans lien
   - réponse : relier deux propositions proches
   - indice : Les deux parties de la phrase parlent-elles du même moment ?
   - explication : Le point-virgule relie deux propositions qui vont ensemble : le jour se lève, et au même moment les oiseaux chantent. Il sépare moins qu’un point, et la suite ne prend pas de majuscule.
6. énoncé : « Léo, range ta chambre. » Que montre la virgule ?
   - lu : Léo, range ta chambre. Que montre la virgule ?
   - choix : Léo est le sujet · on parle à Léo · on fait une liste
   - réponse : on parle à Léo
   - indice : Y a-t-il un sujet écrit devant « range » ?
   - explication : La virgule isole Léo, celui à qui l’on parle ; « range » est à l’impératif, sans sujet. Sans virgule, « Léo range sa chambre » dirait ce que fait Léo.
7. énoncé : « Les élèves, qui étaient fatigués, sont rentrés. » Tous les élèves étaient-ils fatigués ?
   - lu : Les élèves, qui étaient fatigués, sont rentrés. Tous les élèves étaient-ils fatigués ?
   - choix : oui, tous · non, seulement certains
   - réponse : oui, tous
   - indice : La relative est entre virgules. Relis la dernière ligne de la règle.
   - explication : Entre virgules, la relative ajoute une précision sur tous les élèves : ils étaient tous fatigués, et ils sont tous rentrés. On pourrait l’enlever sans changer qui est rentré.
8. énoncé : « Les élèves qui étaient fatigués sont rentrés. » De quels élèves parle la phrase ?
   - lu : Les élèves qui étaient fatigués sont rentrés. De quels élèves parle la phrase ?
   - choix : de tous les élèves · seulement des élèves fatigués
   - réponse : seulement des élèves fatigués
   - indice : Il n’y a pas de virgules autour de la relative. Relis la dernière ligne de la règle.
   - explication : Sans virgules, la relative trie les élèves : la phrase ne parle que de ceux qui étaient fatigués, et ce sont eux qui sont rentrés. Avec des virgules, elle parlerait de tous.
