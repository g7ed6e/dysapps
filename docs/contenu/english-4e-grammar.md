### Niveau 1 · `english-4e-grammar-future-1`

Pour tous les items :
- aide « Le futur avec will » :
  - will + verbe à la base : I will go, she will go.
  - Pas de s, pas de to : she will win.
  - Négation : won’t (will not). Question : Will you…?
  - Pour une prédiction, une promesse, une décision prise sur le moment.

1. énoncé : Tomorrow it … rain.
   - choix : will · is · did
   - réponse : will
   - indice : On parle de l’avenir : quel petit mot met le verbe au futur ?
   - explication : tomorrow = demain : it will rain.
2. énoncé : I think she … win the race.
   - choix : will · wills · is
   - réponse : will
   - indice : Will ne prend jamais de s.
   - explication : she will win : will reste sans s.
3. énoncé : In 2050, cars … fly.
   - choix : will · are · did
   - réponse : will
   - indice : On parle de l’avenir : quel petit mot met le verbe au futur ?
   - explication : En 2050 : une prédiction, cars will fly.
4. énoncé : I … help you, don’t worry!
   - choix : will · am · do
   - réponse : will
   - indice : On parle de l’avenir : quel petit mot met le verbe au futur ?
   - explication : Une promesse : I will help you.
5. énoncé : He … be twelve next month.
   - choix : will · is · has
   - réponse : will
   - indice : On parle de l’avenir : quel petit mot met le verbe au futur ?
   - explication : next month = le mois prochain : he will be.
6. énoncé : We won’t … late.
   - choix : be · are · to be
   - réponse : be
   - indice : Après won’t, le verbe reste à la base, sans to.
   - explication : won’t + base : we won’t be late.
7. énoncé : … you come to my party?
   - choix : Will · Do · Are
   - réponse : Will
   - indice : On parle de l’avenir : quel petit mot met le verbe au futur ?
   - explication : Question au futur : Will you come…?
8. énoncé : They … not go to school next week: it’s the holidays.
   - choix : will · do · are
   - réponse : will
   - indice : On parle de l’avenir : quel petit mot met le verbe au futur ?

### Niveau 1 · `english-4e-grammar-modals-1`

Pour tous les items :
- aide « Can, must, should » :
  - can = pouvoir, savoir (I can swim). can’t = ne pas pouvoir.
  - must = devoir (obligation). mustn’t = interdiction.
  - should = devrait (conseil). shouldn’t = ne devrait pas.
  - Après un modal : verbe à la base, sans to, sans s (she can swim).

1. énoncé : I … swim: I learned when I was five.
   - choix : can · must · should
   - réponse : can
   - indice : Capacité, obligation, interdiction ou conseil ?
   - explication : Savoir faire → can : I can swim.
2. énoncé : You … wear a helmet on a bike: it’s the rule.
   - choix : must · can · may
   - réponse : must
   - indice : Capacité, obligation, interdiction ou conseil ?
   - explication : C’est la règle → must (obligation).
3. énoncé : She … speak three languages.
   - choix : can · must · has
   - réponse : can
   - indice : Capacité, obligation, interdiction ou conseil ?
   - explication : Savoir faire → can : she can speak (sans s).
4. énoncé : You … eat in the library. It’s forbidden!
   - choix : mustn’t · can · should
   - réponse : mustn’t
   - indice : Capacité, obligation, interdiction ou conseil ?
   - explication : Interdit → mustn’t.
5. énoncé : You look tired. You … go to bed.
   - choix : should · can’t · mustn’t
   - réponse : should
   - indice : Capacité, obligation, interdiction ou conseil ?

6. énoncé : … I open the window, please?

   - indice : On demande la permission.

   - choix : shouldn’t · can · should
   - réponse : shouldn’t
   - indice : Capacité, obligation, interdiction ou conseil ?
   - explication : Un conseil de ne pas faire → shouldn’t.
8. énoncé : He … play the guitar very well.
   - choix : can · must · should
   - réponse : can
   - indice : Capacité, obligation, interdiction ou conseil ?
   - explication : Savoir faire → can : he can play (sans s).

### Niveau 1 · `english-4e-grammar-present-perfect-1`

Pour tous les items :
- aide « Le present perfect » :
  - have / has + participe passé (I have seen, she has seen).
  - Expérience : ever = déjà (dans une question), never = jamais.
  - Verbe régulier : participe en -ed (finished). Irrégulier : 3e forme (seen, eaten, been).

1. énoncé : I have … to London twice.
   - choix : been · was · be
   - réponse : been
   - indice : Have / has + participe passé : quelle est la 3e forme du verbe ?
   - explication : be – was – been : I have been.
2. énoncé : She has … Harry Potter three times.
   - choix : read · readed · reads
   - réponse : read
   - indice : Have / has + participe passé : quelle est la 3e forme du verbe ?
   - explication : read – read – read : she has read.
3. énoncé : Have you ever … sushi?
   - choix : eaten · ate · eat
   - réponse : eaten
   - indice : Have / has + participe passé : quelle est la 3e forme du verbe ?
   - explication : eat – ate – eaten : have you ever eaten…?
4. énoncé : We … never seen the sea.
   - choix : have · has · are
   - réponse : have
   - indice : Present perfect : have ou has, selon le sujet.
   - explication : we have never seen : avec we, have.
5. énoncé : He … lost his keys!
   - choix : has · have · is
   - réponse : has
   - indice : Present perfect : have ou has, selon le sujet.
   - explication : he has lost : avec he, has.
6. énoncé : I have never … a horse.
   - choix : ridden · rode · ride
   - réponse : ridden
   - indice : Have / has + participe passé : quelle est la 3e forme du verbe ?
   - explication : ride – rode – ridden : I have never ridden.
7. énoncé : … you ever met a famous person?
   - choix : Have · Did · Do
   - réponse : Have
   - indice : Ever + participe (met) : present perfect.
   - explication : Have you ever met…? : question au present perfect.
8. énoncé : They have … their homework.
   - choix : finished · finish · finishing
   - réponse : finished
   - indice : Have / has + participe passé : quelle est la 3e forme du verbe ?
   - explication : Verbe régulier : finish → finished.
