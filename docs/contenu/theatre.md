# Théâtre des voix

## Dialogues · `dialogues`

- description : Écouter une question et choisir la bonne réponse.
- compétences : c4.en.ecouter.intervention-breve · c4.en.dialoguer.reagir · c3.en.dialoguer.reagir
- langue : en
- consigne : Écoute la question en anglais, puis choisis la bonne réponse.
- bravo : Bonne réplique !
- erreur : {explanation}
- bloc gagné : velours
- blocs : 4
- XP : 14
- monte à : 0.85
- descend à : 0.5

### Niveau 1 · `theatre-dialogues-1`

Pour tous les items :
- indice : Écoute le premier mot : where (où), when (quand), why (pourquoi), who (qui), what (quoi), how (comment).

1. mot : Where do you live?
   - choix : In Manchester. · Every day. · My brother.
   - réponse : In Manchester.
   - explication : Where = où : on répond par un lieu (In Manchester).
2. mot : What time is it?
   - choix : It’s six o’clock. · It’s Monday. · It’s sunny.
   - réponse : It’s six o’clock.
   - explication : What time = quelle heure : on répond par une heure.
3. mot : How old is your sister?
   - choix : She’s fourteen. · She’s tall. · She’s at home.
   - réponse : She’s fourteen.
   - explication : How old = quel âge : on répond par un âge.
4. mot : Who is that boy?
   - choix : He’s my cousin. · He’s in the park. · Yes, he is.
   - réponse : He’s my cousin.
   - explication : Who = qui : on répond par une personne.
5. mot : When is the party?
   - choix : On Saturday. · At my house. · With Tom.
   - réponse : On Saturday.
   - explication : When = quand : on répond par un moment (On Saturday).
6. mot : Why are you late?
   - choix : Because I missed the bus. · At eight o’clock. · By bus.
   - réponse : Because I missed the bus.
   - explication : Why = pourquoi : on répond par because (parce que).
7. mot : How do you go to school?
   - choix : By bike. · At eight. · Because it’s fun.
   - réponse : By bike.
   - explication : How = comment : on répond par un moyen (by bike, à vélo).
8. mot : What’s the weather like?
   - choix : It’s cloudy. · It’s Tuesday. · I like it.
   - réponse : It’s cloudy.
   - explication : What’s the weather like? = Quel temps fait-il ? It’s cloudy, c’est nuageux.

### Niveau 2 · `theatre-dialogues-2`

   - réponse : I was at the cinema.
   - indice : La réponse reprend le temps de la question : did → did, have → have, can → can.
   - explication : last night = hier soir : on répond au passé (I was).
2. mot : What are you doing?

   - indice : La réponse reprend le temps de la question : did → did, have → have, can → can.

   - indice : La réponse reprend le temps de la question : did → did, have → have, can → can.

6. mot : Can you swim?

- compétences : c4.en.langue.groupe-nominal

- blocs : 4
- XP : 14
- monte à : 0.85

- trou lu : blank

### Niveau 1 · `theatre-quantites-1`

Pour tous les items :
- aide « Some, any, much, many » :
  - Phrase affirmative : some (There is some milk).
  - Négation et question : any (There isn’t any milk. Is there any milk?)
  - Demande polie : some (Can I have some bread?)
  - much + ce qui ne se compte pas (milk, money, sugar) ; many + ce qui se compte, au pluriel (apples, friends).

1. énoncé : There is … milk in the fridge.
   - choix : some · any · many
   - réponse : some
   - indice : Affirmation, négation ou question ? Ça se compte ou pas ?
   - explication : Phrase affirmative : some.
2. énoncé : Are there … apples?
   - choix : any · some · much
   - réponse : any
   - indice : Affirmation, négation ou question ? Ça se compte ou pas ?
   - explication : Question : any.
3. énoncé : I haven’t got … money.
   - choix : any · some · many
   - réponse : any
   - indice : Affirmation, négation ou question ? Ça se compte ou pas ?
   - explication : Négation : any.
4. énoncé : How … sugar do you want?
   - choix : much · many · any
   - réponse : much
   - indice : Le sucre, ça se compte ?
   - explication : sugar ne se compte pas : how much.
5. énoncé : How … brothers have you got?
   - choix : many · much · some
   - réponse : many
   - indice : Les frères, ça se compte ?
   - explication : brothers se comptent : how many.
6. énoncé : There aren’t … students in the classroom.
   - choix : any · some · much
   - réponse : any
   - indice : Affirmation, négation ou question ? Ça se compte ou pas ?
   - explication : Négation : any.
7. énoncé : Can I have … bread, please?
   - choix : some · any · many
   - réponse : some
   - indice : C’est une demande polie.
   - explication : Demande polie : some, même dans une question.
8. énoncé : She doesn’t have … friends here.
   - choix : many · much · some
   - réponse : many
   - indice : Les amis, ça se compte ?
   - explication : friends se comptent : many.

### Niveau 2 · `theatre-quantites-2`

Pour tous les items :
- aide « Beaucoup, peu, trop, assez » :
  - a lot of = beaucoup de (avec tout).
  - a few = quelques (ce qui se compte) ; a little = un peu de (ce qui ne se compte pas).
  - too much / too many = trop de.
  - enough = assez de.

1. énoncé : I have … friends: only two or three.
   - choix : a few · a little · a lot of
   - réponse : a few
   - indice : Deux ou trois amis : peu, et ça se compte.
   - explication : a few friends = quelques amis (ça se compte).
2. énoncé : There is … water left: just a drop.
   - choix : a little · a few · many
   - réponse : a little
   - indice : Une goutte d’eau : peu, et ça ne se compte pas.
   - explication : a little water = un peu d’eau (ça ne se compte pas).
3. énoncé : He has got … books: more than a hundred!
   - choix : a lot of · a few · a little
   - réponse : a lot of
   - indice : Plus de cent : beaucoup.
   - explication : a lot of books = beaucoup de livres.
4. énoncé : Hurry up! We haven’t got … time.
   - choix : much · many · a few
   - réponse : much
   - indice : Le temps, ça se compte ?
   - explication : time ne se compte pas : not much time.
5. énoncé : There are too … cars in this street.
   - choix : many · much · little
   - réponse : many
   - indice : Les voitures, ça se compte.
   - explication : too many cars = trop de voitures (ça se compte).
6. énoncé : Don’t eat too … chocolate!
   - choix : much · many · few
   - réponse : much
   - indice : Le chocolat, ça se compte ?
   - explication : too much chocolate = trop de chocolat (ça ne se compte pas).
7. énoncé : Is there … cheese for everybody?
   - choix : enough · many · a few
   - réponse : enough
   - indice : Pour tout le monde : assez ?
   - explication : enough cheese = assez de fromage.
8. énoncé : We need … eggs: two or three.
   - choix : a few · a little · much
   - réponse : a few
   - indice : Deux ou trois œufs : peu, et ça se compte.
   - explication : a few eggs = quelques œufs.

## Prétérit irrégulier · `preterit-irregulier`

- description : Went, saw, bought : les verbes irréguliers au passé.
- compétences : c4.en.langue.temps-verbaux
- langue : en
- consigne : Choisis le mot qui complète la phrase en anglais. La règle est affichée : lis-la avant de répondre.
- bravo : Bien dit !
- erreur : {explanation}
- bloc gagné : velours
- blocs : 4
- XP : 14
- monte à : 0.85
- descend à : 0.5

Pour tous les items :
- trou lu : blank

### Niveau 1 · `theatre-preterit-irregulier-1`

Pour tous les items :
- indice : C’est un verbe irrégulier : pas de -ed. Quelle est sa deuxième forme ?
- aide « Prétérit : les verbes irréguliers » :
  - Les verbes irréguliers ne prennent pas -ed au prétérit.
  - go → went, see → saw, do → did, eat → ate
  - buy → bought, write → wrote, come → came, give → gave
  - Révise-les dans la mission Verbes irréguliers de la page Anglais.

1. énoncé : Yesterday I … to the beach.
   - choix : went · goed · gone
   - réponse : went
   - explication : go – went – gone : au prétérit, went.
2. énoncé : She … a new bike last week.
   - choix : bought · buyed · brought
   - réponse : bought
   - explication : buy – bought – bought (brought vient de bring).
3. énoncé : We … a film last night.
   - choix : saw · seed · seen
   - réponse : saw
   - explication : see – saw – seen : au prétérit, saw.
4. énoncé : He … his homework yesterday.
   - choix : did · doed · done
   - réponse : did
   - explication : do – did – done : au prétérit, did.
5. énoncé : They … pizza for dinner.
   - choix : ate · eated · eaten
   - réponse : ate
   - explication : eat – ate – eaten : au prétérit, ate.
6. énoncé : I … a letter to my friend.
   - choix : wrote · writed · written
   - réponse : wrote
   - explication : write – wrote – written : au prétérit, wrote.
7. énoncé : Lina … home at six.
   - choix : came · comed · come
   - réponse : came
   - explication : come – came – come : au prétérit, came.
8. énoncé : My dad … me a present.
   - choix : gave · gived · given
   - réponse : gave
   - explication : give – gave – given : au prétérit, gave.

### Niveau 2 · `theatre-preterit-irregulier-2`

Pour tous les items :
- aide « Prétérit : irréguliers, négation, question » :
  - lose → lost, begin → began, sing → sang, take → took
  - break → broke, hear → heard, win → won
  - Négation et question : did + base (I didn’t go. Did you see?)

1. énoncé : I … my keys this morning!
   - choix : lost · losed · lose
   - réponse : lost
   - indice : C’est un verbe irrégulier : pas de -ed. Quelle est sa deuxième forme ?
   - explication : lose – lost – lost : au prétérit, lost.
2. énoncé : The film … at eight.
   - choix : began · beginned · begun
   - réponse : began
   - indice : C’est un verbe irrégulier : pas de -ed. Quelle est sa deuxième forme ?
   - explication : begin – began – begun : au prétérit, began.
3. énoncé : She … a beautiful song.
   - choix : sang · singed · sung
   - réponse : sang
   - indice : C’est un verbe irrégulier : pas de -ed. Quelle est sa deuxième forme ?
   - explication : sing – sang – sung : au prétérit, sang.
4. énoncé : We … the bus to London.
   - choix : took · taked · taken
   - réponse : took
   - indice : C’est un verbe irrégulier : pas de -ed. Quelle est sa deuxième forme ?
   - explication : take – took – taken : au prétérit, took.
5. énoncé : He … the window with his ball.
   - choix : broke · breaked · broken
   - réponse : broke
   - indice : C’est un verbe irrégulier : pas de -ed. Quelle est sa deuxième forme ?
   - explication : break – broke – broken : au prétérit, broke.
6. énoncé : I … a strange noise last night.
   - choix : heard · heared · hear
   - réponse : heard
   - indice : C’est un verbe irrégulier : pas de -ed. Quelle est sa deuxième forme ?
   - explication : hear – heard – heard : au prétérit, heard.
7. énoncé : They didn’t … the match.
   - choix : win · won · winned
   - réponse : win
   - indice : Après didn’t, le verbe reste à la base.
   - explication : didn’t + base : they didn’t win.
8. énoncé : … you see the fireworks last night?
   - choix : Did · Saw · Do
   - réponse : Did
   - indice : Question au passé : quel auxiliaire ?
   - explication : Question au passé : Did you see…?
