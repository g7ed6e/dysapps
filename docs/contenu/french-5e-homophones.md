### Niveau 1 · `french-5e-homophones-choices-1`

- consigne : Choisis le bon mot pour compléter la phrase. La règle est affichée : lis-la avant de répondre.
- programme : c4.fr.5e.vocabulaire.orthographe · c4.fr.5e.grammaire.classes-de-mots · c3.fr.langue.orthographe-grammaticale

Pour tous les items :
- aide « Homophones » :
  - ma, ta : devant un nom (ma chambre, ta veste).
  - m’a, t’a = me + a, te + a : on peut dire « m’avait », « t’avait ».
  - sans = pas de. s’en = se + en (il s’en va).
  - dans = à l’intérieur. d’en = de + en (d’en parler).

1. clé : french-5e-homophones-choices-1-2
   - énoncé : Il est parti … dire au revoir.
   - choix : sans · s’en · sang
   - réponse : sans
   - indice : « sans » = pas de, l’absence.
   - explication : Il est parti sans dire au revoir : « sans » signifie l’absence.
2. clé : french-5e-homophones-choices-1-3
   - énoncé : Elle … va tout de suite.
   - choix : sans · s’en · sent
   - réponse : s’en
   - indice : « s’en aller » : on peut dire « je m’en vais ».
   - explication : « Elle s’en va » : verbe s’en aller, se + en.
3. clé : french-5e-homophones-choices-1-4
   - énoncé : Le chat dort … le panier.
   - choix : dans · d’en · dent
   - réponse : dans
   - indice : « dans » = à l’intérieur de.
   - explication : Le chat dort dans le panier : à l’intérieur.
4. clé : french-5e-homophones-choices-1-5
   - énoncé : Arrête … parler !
   - choix : dans · d’en · dent
   - réponse : d’en
   - indice : « d’en » = de + en : arrête de parler de cela.
   - explication : Arrête d’en parler : de + en.
5. clé : ma-oncle
   - énoncé : Mon oncle … offert un ballon.
   - choix : ma · m’a · m’as
   - réponse : m’a
   - indice : Remplace par « m’avait » : si ça marche, c’est « m’a ».
   - explication : « Mon oncle m’avait offert un ballon » fonctionne : c’est « m’a », me + a, le verbe avoir. « M’as » va avec tu : tu m’as offert.
6. clé : ma-chambre

   - choix : ma · m’a · m’as
   - réponse : ma
   - indice : Remplace par « m’avait » : si ça ne marche pas, c’est « ma ».

8. clé : ta-veste

   - indice : Remplace par « t’avait » : si ça ne marche pas, c’est « ta ».

- aide « Homophones » :

### Niveau 1 · `french-5e-homophones-homophone-sentences-1`

Pour tous les items :
- aide « Deux mots à choisir » :
  - ses = les siens · ces = ceux-là · c’est = cela est · s’est = se + est.
  - son = le sien · sont = verbe être (ils sont).
  - a = avait · à = préposition.
  - on = quelqu’un · ont = verbe avoir (ils ont).

1. énoncé : … amis … partis tôt.
   - lu : " (mot manquant)  amis  (mot manquant)  partis tôt."
   - choix : Ses / sont · Ces / son · Ses / son
   - réponse : Ses / sont
   - indice : « les siens » puis « étaient ».
   - explication : Ses amis (les siens) sont (étaient) partis tôt.
2. énoncé : … chaussures-là … à lui.
   - lu : " (mot manquant)  chaussures-là  (mot manquant)  à lui."
   - choix : Ces / son · Ces / sont · Ses / sont
   - réponse : Ces / sont
   - indice : « -là » montre : ces. « étaient » : sont.
   - explication : Ces chaussures-là (on montre) sont (étaient) à lui.
3. énoncé : Il … levé … sept heures.
   - lu : Il  (mot manquant)  levé  (mot manquant)  sept heures.
   - choix : s’est / à · c’est / a · s’est / a
   - réponse : s’est / à
   - indice : « je me suis levé » : s’est. « avait » ne marche pas devant sept heures : à.
   - explication : Il s’est levé (verbe se lever) à sept heures (préposition).
4. énoncé : … vrai, il … raison.
   - lu : " (mot manquant)  vrai, il  (mot manquant)  raison."
   - choix : C’est / a · S’est / à · C’est / à
   - réponse : C’est / a
   - indice : « cela est » : c’est. « avait raison » : a.
   - explication : C’est vrai (cela est), il a (avait) raison.
5. énoncé : … dit qu’ils … gagné.
   - lu : " (mot manquant)  dit qu’ils  (mot manquant)  gagné."
   - choix : On / ont · Ont / on · On / on
   - réponse : On / ont
   - indice : « quelqu’un dit » : on. « ils avaient » : ont.
   - explication : On dit (quelqu’un) qu’ils ont (avaient) gagné.
6. énoncé : Elle … acheté … vélo.
   - lu : Elle  (mot manquant)  acheté  (mot manquant)  vélo.
   - choix : a / son · à / son · a / sont
   - réponse : a / son
   - indice : « avait acheté » : a. « le sien » : son.
   - explication : Elle a (avait) acheté son (le sien) vélo.
7. énoncé : … élèves … oublié leurs cahiers.
   - lu : " (mot manquant)  élèves  (mot manquant)  oublié leurs cahiers."
   - choix : Ces / ont · Ses / on · Ces / on
   - réponse : Ces / ont
   - indice : « ces élèves-là » : ces. « ils avaient » : ont.
   - explication : Ces élèves (ceux-là) ont (avaient) oublié leurs cahiers.
8. énoncé : … la fête, … cousins dansent.
   - lu : " (mot manquant)  la fête,  (mot manquant)  cousins dansent."
   - choix : À / ses · A / ces · A / ses
   - réponse : À / ses
   - indice : « avait » ne marche pas : à. « les siens » : ses.

### Niveau 1 · `french-5e-homophones-participles-1`

- consigne : Choisis la forme qui complète la phrase : participe passé ou infinitif. La règle est affichée.

Pour tous les items :
- aide « Participe passé ou infinitif ? » :
  - -é ou -er ? Remplace le verbe par « vendu » ou par « vendre ».
  - Tu peux dire « vendre » : c’est l’infinitif, en -er.
  - Tu peux dire « vendu » : c’est le participe passé, en -é.
  - Avec être, le participe s’accorde avec le sujet. Elles sont venues.
  - Trouve le sujet : qui est-ce qui ? Puis son genre et son nombre.

1. énoncé : Mes cousines sont … hier soir.
   - choix : arrivées · arrivé · arriver
   - réponse : arrivées
   - indice : Qui est-ce qui est arrivé ? Une fille ou un garçon, un ou plusieurs ?
   - explication : On peut dire « sont vendues » : c’est le participe passé. Avec être, il s’accorde avec le sujet « mes cousines », féminin pluriel : « arrivées ». « arrivé », sans accord, irait avec un seul garçon. On ne dit pas « sont vendre » : « arriver » ne va pas.
2. énoncé : Il va … ses devoirs avant le dîner.
   - choix : terminer · terminé · terminés
   - réponse : terminer
   - indice : Remplace par « vendre » ou « vendu ».
   - explication : On dit « il va vendre », pas « il va vendu » : après « va », c’est l’infinitif, « terminer », en -er.
3. énoncé : Ma grand-mère est … en Bretagne.
   - choix : née · né · nés
   - réponse : née
   - indice : Qui est née ? Une femme ou un homme ?
   - explication : Avec être, le participe s’accorde avec le sujet « ma grand-mère », féminin singulier : « née », avec un e. « né » irait avec « mon grand-père », « nés » avec plusieurs personnes.
4. énoncé : Ma mère veut … le salon.
   - choix : ranger · rangé · rangée
   - réponse : ranger
   - indice : Remplace par « vendre » ou « vendu ».
   - explication : On dit « elle veut vendre », pas « elle veut vendu » : après « veut », c’est l’infinitif, « ranger », en -er. Le verbe « veut » n’est pas l’auxiliaire être.
5. énoncé : Les garçons sont … de la cantine.
   - choix : sortis · sorti · sortir
   - réponse : sortis
   - indice : Qui est-ce qui est sorti ? Un ou plusieurs ?
   - explication : Avec être, le participe s’accorde avec le sujet « les garçons », masculin pluriel : « sortis », avec un s. « sorti » irait avec un seul garçon. On ne dit pas « sont vendre » : « sortir » ne va pas.
6. énoncé : Papa doit … la voiture devant la maison.
   - choix : garer · garé · garée
   - réponse : garer
   - indice : Remplace par « vendre » ou « vendu ».
   - explication : On dit « il doit vendre », pas « il doit vendu » : après « doit », c’est l’infinitif, « garer », en -er. « La voiture » vient après : elle ne change rien.
7. énoncé : Elles sont … danser au gymnase.
   - choix : allées · allé · aller
   - réponse : allées
   - indice : Le verbe être est juste avant le trou. Qui est-ce qui est allé ?
   - explication : « sont » est l’auxiliaire être : on peut dire « elles sont venues », c’est le participe passé. Il s’accorde avec « elles », féminin pluriel : « allées ». « allé » oublie l’accord ; « aller » ne va pas, car on ne dit pas « elles sont vendre ». Le verbe qui suit, « danser », est à l’infinitif.
8. énoncé : Après le match, les joueuses sont … dans les vestiaires.

### Niveau 1 · `french-5e-homophones-word-meaning-1`

- programme : c4.fr.5e.vocabulaire.sens · c4.fr.5e.vocabulaire.relations · c4.fr.5e.vocabulaire.reemploi

Pour tous les items :
- aide « Le sens des mots » :
  - Synonymes : un sens proche (un bateau, un navire).
  - Antonymes : un sens contraire (ouvrir, fermer).
  - Homonymes : le même son, un autre sens (le pain, il peint).
  - Sens propre : le sens concret. Sens figuré : une image (une tempête d’applaudissements).
  - Un mot inconnu ? Relis la phrase : ce qui l’entoure aide à trouver son sens.

1. énoncé : « Débuter » et « … » sont synonymes.
   - choix : commencer · terminer · continuer
   - réponse : commencer
   - indice : Des synonymes ont un sens proche. Quand un film débute, que fait-il ?
   - explication : « Débuter » et « commencer » ont un sens proche : ce sont des synonymes. « Terminer » dit le contraire : c’est un antonyme.
2. énoncé : « Ajouter » et « … » sont des antonymes.
   - choix : enlever · rajouter · mettre
   - réponse : enlever
   - indice : Des antonymes ont un sens contraire.
   - explication : « Enlever » dit le contraire d’« ajouter » : ce sont des antonymes. « Rajouter » et « mettre » ont un sens proche d’« ajouter ».
3. énoncé : La rue est étroite, mais l’avenue est … .
   - choix : large · longue · fine
   - réponse : large
   - indice : « mais » annonce le contraire d’« étroite ».
   - explication : Le contraire d’« étroite », c’est « large » : « mais » oppose les deux. « Longue » est le contraire de « courte », et « fine » a un sens proche d’« étroite ».
4. énoncé : « Le sel » et « la selle » se disent pareil. Ce sont des … .
   - choix : homonymes · synonymes · antonymes
   - réponse : homonymes
   - indice : Les deux mots ont le même son. Ont-ils le même sens ?
   - explication : Le sel se met dans la soupe, la selle se pose sur un cheval : même son, sens différent, ce sont des homonymes. Des synonymes auraient un sens proche.
5. énoncé : Elle a la tête dans les nuages : elle est … .
   - choix : distraite · très grande · dans un avion
   - réponse : distraite
   - indice : Sa tête n’est pas vraiment dans le ciel : c’est une image.
   - explication : C’est le sens figuré : elle rêve, elle n’écoute pas, elle est distraite. « Très grande » et « dans un avion » prennent la phrase au sens propre.
6. énoncé : Frigorifié, Tom tremble et souffle sur ses doigts : il a très … .
   - choix : froid · peur · faim
   - réponse : froid
   - indice : Pourquoi souffle-t-on sur ses doigts ? Regarde aussi le début de « frigorifié ».
   - explication : Tom souffle sur ses doigts pour les réchauffer, et « frigorifié » commence comme « frigo » : il a très froid. On peut trembler de peur, mais on ne souffle pas sur ses doigts.
7. énoncé : Exténuée par la randonnée, Inès se couche tout de suite : elle est très … .
   - choix : fatiguée · contente · en retard
   - réponse : fatiguée
   - indice : Relis la phrase : que fait Inès juste après la randonnée ?
   - explication : Après une longue marche, Inès se couche tout de suite : « exténuée » veut dire très fatiguée. La phrase ne parle ni de joie ni de retard.
8. énoncé : Ce cri dans la nuit m’a glacé le sang : il m’a fait très … .
   - choix : peur · froid · mal
   - réponse : peur
   - indice : Le sang n’a pas vraiment gelé : c’est une image.
   - explication : « Glacer le sang » est au sens figuré : c’est faire très peur. « Froid » prend l’expression au sens propre, et un cri ne fait pas mal.

### Niveau 2 · `french-5e-homophones-word-meaning-2`

- programme : c4.fr.5e.vocabulaire.formation · c4.fr.5e.vocabulaire.relations · c4.fr.5e.vocabulaire.reemploi

Pour tous les items :
- aide « Former les mots » :
  - dé- = le contraire (coller, décoller). -ette = petit (fillette). -eur = qui fait (chanteur).
  - Du latin : aqua = eau, -vore = qui mange. Du grec : chrono = temps.
  - Une lettre muette ? Cherche un mot de la même famille : un bord, border.
  - Registres : familier entre amis, courant avec tout le monde, soutenu pour un écrit soigné.

1. énoncé : Le puzzle est fini : Léo le … pour le ranger dans sa boîte.
   - choix : défait · refait · fait
   - réponse : défait
   - indice : Regarde le début des mots : quel préfixe dit le contraire ?
   - explication : Dé- dit le contraire : défaire, c’est le contraire de faire. Pour ranger le puzzle fini, Léo le défait. Re- veut dire « de nouveau » : le refaire, ce serait le recommencer.
2. énoncé : Un petit camion s’appelle … .
   - choix : une camionnette · un camionneur · un camionnage
   - réponse : une camionnette
   - indice : Quel suffixe veut dire « petit » ?
   - explication : Le suffixe -ette veut dire petit : une camionnette est un petit camion. Avec -eur, le camionneur est celui qui conduit le camion. Le camionnage, c’est le transport en camion.
3. énoncé : Le nénuphar est une plante aquatique : il pousse dans l’… .
   - choix : eau · ombre · herbe
   - réponse : eau
   - indice : Regarde le début d’« aquatique » : que veut dire aqua en latin ?
   - explication : Aqua veut dire eau en latin : une plante aquatique pousse dans l’eau, comme le nénuphar.
4. énoncé : Un animal carnivore mange … .
   - choix : de la viande · des plantes · de tout
   - réponse : de la viande
   - indice : -vore veut dire « qui mange ». Que mange le lion ?
   - explication : -vore veut dire « qui mange », et carni- vient d’un mot latin qui veut dire la chair, la viande. Celui qui mange des plantes est herbivore, celui qui mange de tout est omnivore.
5. énoncé : Avec un chronomètre, on mesure le … .
   - choix : temps · poids · bruit
   - réponse : temps
   - indice : Regarde le début du mot : que veut dire chrono en grec ?
   - explication : Chrono veut dire temps en grec : le chronomètre mesure le temps. Le poids se mesure avec une balance.
6. énoncé : Le cheval part au … dans le pré.
   - choix : galop · galot · galo
   - réponse : galop
   - indice : Cherche le verbe de la même famille : on y entend la dernière lettre.
   - explication : Le verbe de la même famille, c’est « galoper » : on y entend le p. On écrit donc « galop », avec un p muet à la fin.
7. énoncé : « Un toubib » est un mot familier. Le mot courant, c’est … .
   - choix : un médecin · un praticien · un infirmier
   - réponse : un médecin
   - indice : Le mot courant, c’est celui qu’on dit à tout le monde.
   - explication : « Un toubib » est familier ; le mot courant, c’est « un médecin ». « Un praticien » est un mot soutenu, et un infirmier fait un autre métier.
8. énoncé : Au lieu de « j’ai la flemme », on dit à un professeur : « Je n’ai pas … . »
   - choix : envie · la flemme · la pêche
   - réponse : envie
   - indice : Avec un professeur, on choisit le registre courant : pas de mot familier.
   - explication : « J’ai la flemme » est familier. Avec un professeur, on dit en registre courant : « Je n’ai pas envie. » « La flemme » et « la pêche » restent des mots familiers.
