### Niveau 1 · `english-3e-grammar-for-since-1`

Pour tous les items :
- indice : Une durée (for), un point de départ (since), ou « il y a » (ago) ?
- aide « For, since, ago » :
  - for + une durée (for ten years, for a week)
  - since + un point de départ (since Monday, since 2019)
  - ago = il y a, avec le prétérit (two days ago)
  - for / since → present perfect : I have lived here for ten years.

1. énoncé : I have lived here … ten years.
   - choix : for · since · ago
   - réponse : for
   - explication : ten years est une durée → for.
2. énoncé : She has been ill … Monday.
   - choix : since · for · ago
   - réponse : since
   - explication : Monday est un point de départ → since.
3. énoncé : We have known each other … 2019.
   - choix : since · for · ago
   - réponse : since
   - explication : 2019 est un point de départ → since.
4. énoncé : They have been married … a long time.
   - choix : for · since · ago
   - réponse : for
   - explication : a long time est une durée → for.
5. énoncé : I saw him two days … .
   - choix : ago · for · since
   - réponse : ago
   - explication : two days ago = il y a deux jours (avec le prétérit saw).
6. énoncé : He has played the guitar … he was six.
   - choix : since · for · ago
   - réponse : since
   - explication : he was six est un point de départ → since.
7. énoncé : I have waited … twenty minutes!
   - choix : for · since · ago
   - réponse : for
   - explication : twenty minutes est une durée → for.
8. énoncé : She moved to London three years … .
   - choix : ago · for · since
   - réponse : ago
   - explication : three years ago = il y a trois ans (avec le prétérit moved).

### Niveau 2 · `english-3e-grammar-for-since-2`

Pour tous les items :
- indice : C’est terminé (une date du passé) ou ça dure jusqu’à maintenant ?
- aide « Present perfect ou prétérit ? » :
  - Moment terminé et daté (yesterday, in 2015, last summer, ago) : prétérit.
  - Jusqu’à maintenant (since, for, how long) : present perfect.
  - When…? → prétérit ; How long…? → present perfect.

1. énoncé : I … in Paris since 2015.
   - choix : have lived · lived · live
   - réponse : have lived
   - explication : since 2015 : jusqu’à maintenant → present perfect.
2. énoncé : I … in Paris in 2015.
   - choix : lived · have lived · live
   - réponse : lived
   - explication : in 2015 : une date terminée → prétérit.
3. énoncé : We … the film yesterday.
   - choix : saw · have seen · see
   - réponse : saw
   - explication : yesterday : terminé → prétérit.
4. énoncé : She … here since nine o’clock.
   - choix : has been · was · is
   - réponse : has been
   - explication : since nine o’clock : jusqu’à maintenant → present perfect.
5. énoncé : They … to Spain last summer.
   - choix : went · have gone · go
   - réponse : went
   - explication : last summer : terminé → prétérit.
6. énoncé : How long … you known her?
   - choix : have · did · do
   - réponse : have
   - explication : How long…? : jusqu’à maintenant → present perfect.
7. énoncé : When … you arrive? — Last night.
   - choix : did · have · do
   - réponse : did
   - explication : When…? : un moment précis du passé → prétérit.
8. énoncé : He … his leg three weeks ago.
   - choix : broke · has broken · breaks
   - réponse : broke
   - explication : three weeks ago : terminé → prétérit.

### Niveau 1 · `english-3e-grammar-if-1`

Pour tous les items :
- aide « If : le réel » :
  - Toujours vrai : If + présent, présent (If you heat ice, it melts).
  - Futur possible : If + présent, will + verbe (If it rains, we will stay).
  - Jamais will juste après if !

1. énoncé : If you heat ice, it … .
   - choix : melts · melted · melting
   - réponse : melts
   - indice : Après if : le présent. Dans l’autre partie : présent (toujours vrai) ou will (futur) ?
   - explication : Toujours vrai : If + présent, présent → it melts.
2. énoncé : If it rains tomorrow, we … at home.
   - choix : will stay · stayed · would stay
   - réponse : will stay
   - indice : Après if : le présent. Dans l’autre partie : présent (toujours vrai) ou will (futur) ?
   - explication : tomorrow : futur possible → will stay.
3. énoncé : If you … hard, you will pass.
   - choix : work · will work · worked
   - réponse : work
   - indice : Juste après if : pas de will.
   - explication : Après if : présent → If you work.
4. énoncé : If she comes, I … happy.
   - choix : will be · was · would be
   - réponse : will be
   - indice : Après if : le présent. Dans l’autre partie : présent (toujours vrai) ou will (futur) ?
   - explication : If + présent (comes) → will be.
5. énoncé : I’ll call you if I … time.
   - choix : have · will have · had
   - réponse : have
   - indice : Juste après if : pas de will.
   - explication : Après if : présent → if I have time.
6. énoncé : If you mix red and blue, you … purple.
   - choix : get · got · getting
   - réponse : get
   - indice : Après if : le présent. Dans l’autre partie : présent (toujours vrai) ou will (futur) ?
   - explication : Toujours vrai : If + présent, présent → you get purple.
7. énoncé : If you don’t hurry, you … the bus.
   - choix : will miss · miss · missed
   - réponse : will miss
   - indice : Après if : le présent. Dans l’autre partie : présent (toujours vrai) ou will (futur) ?
   - explication : Futur possible → you will miss the bus.
8. énoncé : What will you do if it … sunny?
   - choix : is · will be · was
   - réponse : is
   - indice : Juste après if : pas de will.
   - explication : Après if : présent → if it is sunny.

### Niveau 2 · `english-3e-grammar-if-2`

Pour tous les items :
- indice : Réel ou imaginaire ? If + présent → will ; if + prétérit → would.
- aide « If : l’imaginaire » :
  - Situation imaginaire : If + prétérit, would + verbe (If I had wings, I would fly).
  - If I were you = à ta place (were avec toutes les personnes).
  - Possible : If + présent, will. Imaginaire : If + prétérit, would.

1. énoncé : If I … rich, I would buy a castle.
   - choix : were · am · will be
   - réponse : were
   - explication : Imaginaire → If I were (were avec I aussi).
2. énoncé : If I had wings, I … fly.
   - choix : would · will · am
   - réponse : would
   - explication : If + prétérit (had) → would fly.
3. énoncé : If she … the answer, she would tell us.
   - choix : knew · knows · will know
   - réponse : knew
   - explication : would dans l’autre partie → if + prétérit : knew.
4. énoncé : What would you do if you … a million pounds?
   - choix : won · win · will win
   - réponse : won
   - explication : would → if + prétérit : won.
5. énoncé : If we lived by the sea, we … every day.
   - choix : would swim · will swim · swim
   - réponse : would swim
   - explication : If + prétérit (lived) → would swim.
6. énoncé : I … help you if I had time.
   - choix : would · will · did
   - réponse : would
   - explication : if I had (prétérit) → I would help.
7. énoncé : If I … you, I would study more.
   - choix : were · am · will be
   - réponse : were
   - explication : If I were you = à ta place.
8. énoncé : If it rains, I … my umbrella.
   - choix : will take · would take · took
   - réponse : will take
   - explication : If + présent (rains) : c’est possible → will take.

### Niveau 1 · `english-3e-grammar-passive-1`

Pour tous les items :
- aide « Le passif » :
  - Passif : be + participe passé (is spoken, was painted).
  - Le temps se met sur be : is / are (présent), was / were (passé).

2. énoncé : These cars … made in Japan.
   - choix : are · is · be

3. énoncé : The Mona Lisa … painted by Leonardo da Vinci.
   - choix : was · is · were

   - indice : Be + participe passé : quelle forme de be (présent ou passé, singulier ou pluriel) ?

4. énoncé : The letters … written yesterday.
   - choix : were · was · are
   - réponse : were
   - indice : Be + participe passé : quelle forme de be (présent ou passé, singulier ou pluriel) ?

7. énoncé : The windows were … last week.

   - indice : Après be, le participe passé : 3e forme.

### Niveau 1 · `english-3e-grammar-messages-1`

- consigne : Lis la question, puis le document en anglais. Choisis la bonne réponse. Le lexique est affiché.

Pour tous les items :
- langue des choix : fr
- aide « Panneaux et consignes » :
  - Lis d’abord la question, puis cherche dans le document le mot qui répond.
  - do not = ne pas ; no entry = entrée interdite ; please = s’il te plaît ; only = seulement
  - mind = attention à ; use = utiliser ; keep = garder
  - first floor = premier étage ; second floor = deuxième étage

1. énoncé : Staff only
   - question : Qui a le droit de passer cette porte ?
   - lu : Staff only.
   - choix : Seulement les employés · Tout le monde · Seulement les clients
   - réponse : Seulement les employés
   - indice : Only veut dire « seulement ». Qui passe derrière le comptoir d’un magasin ?
   - explication : staff = le personnel, les gens qui travaillent ici ; only = seulement. Les clients (customers) n’ont pas le droit d’entrer.
2. énoncé : "In case of fire\nDo not use the lift.\nUse the stairs."
   - question : En cas d’incendie, que ne dois-tu pas prendre ?
   - lu : In case of fire. Do not use the lift. Use the stairs.
   - choix : L’ascenseur · L’escalier · La sortie de secours
   - réponse : L’ascenseur
   - indice : Cherche la phrase qui commence par Do not : elle dit ce qu’il ne faut pas faire.
   - explication : do not use the lift = ne prends pas l’ascenseur (lift = ascenseur, en anglais britannique). Use the stairs dit le contraire : prends l’escalier.
3. énoncé : "No entry\nPlease use the side door."
   - question : Par où entres-tu dans le bâtiment ?
   - lu : No entry. Please use the side door.
   - choix : Par la porte de côté · Par cette porte · Par la porte de derrière
   - réponse : Par la porte de côté
   - indice : No entry : peut-on entrer ici ? La deuxième ligne dit par où passer.
   - explication : no entry = entrée interdite : on n’entre pas par cette porte. Use the side door = passe par la porte de côté (side = le côté ; derrière se dit back).
4. énoncé : "Work in pairs.\nAsk your partner three questions."
   - question : Avec qui travailles-tu ?
   - lu : Work in pairs. Ask your partner three questions.
   - choix : Avec un camarade · Tout seul · Avec trois camarades
   - réponse : Avec un camarade
   - indice : Pair, c’est une paire : combien de chaussures dans une paire ?
   - explication : in pairs = par deux : tu travailles avec un camarade, your partner. Three, c’est le nombre de questions à lui poser, pas de camarades.
5. énoncé : Match each word with the right picture.
   - question : Que dois-tu faire ?
   - lu : Match each word with the right picture.
   - choix : Relier chaque mot à la bonne image · Dessiner chaque mot · Écrire un mot sous chaque image
   - réponse : Relier chaque mot à la bonne image
   - indice : Match, ici, ce n’est pas un match de foot : on met ensemble deux choses qui vont ensemble.
   - explication : match = associer, relier : chaque mot va avec la bonne image (the right picture). Dessiner se dit draw, écrire se dit write.
6. énoncé : "Toilets: first floor\nCafé: ground floor\nLibrary: second floor"
   - question : À quel étage est le café ?
   - lu : Toilets, first floor. Café, ground floor. Library, second floor.
   - choix : Au rez-de-chaussée · Au premier étage · Au deuxième étage
   - réponse : Au rez-de-chaussée
   - indice : Trouve la ligne du café. Ground veut dire « le sol ».
   - explication : ground floor = le rez-de-chaussée, l’étage au niveau du sol (ground). Au Royaume-Uni, first floor est le premier étage, au-dessus.
7. énoncé : "Dogs welcome\nPlease keep your dog on a lead."
   - question : Que demande ce panneau, à l’entrée du parc ?
   - lu : Dogs welcome. Please keep your dog on a lead.
   - choix : Tenir son chien en laisse · Laisser son chien courir librement · Laisser son chien à l’entrée
   - réponse : Tenir son chien en laisse
   - indice : Dogs welcome : les chiens sont-ils interdits ? Puis lis la phrase avec keep.
   - explication : dogs welcome = les chiens sont les bienvenus ; keep your dog on a lead = garde ton chien en laisse (a lead = une laisse). Il entre, mais attaché.
8. énoncé : Mind the step
   - question : À quoi dois-tu faire attention en entrant ?
   - lu : Mind the step.
   - choix : À la marche · À la porte · À ta tête
   - réponse : À la marche
   - indice : Mind veut dire « attention à » : regarde le mot qui suit.
   - explication : mind the step = attention à la marche (a step = une marche, un pas). Attention à ta tête se dirait mind your head.

### Niveau 2 · `english-3e-grammar-messages-2`

- consigne : Lis la question, puis le message en anglais, et choisis la bonne réponse. Le lexique est affiché.

Pour tous les items :
- aide « Lire un message » :
  - Lis d’abord la question, puis cherche dans le message la phrase qui répond.
  - Dear = cher, chère (au début) ; see you = à bientôt ; love = je t’embrasse (à la fin)
  - pm = après midi : on ajoute 12 (6 pm = 18 h)
  - past = après, to = avant : ten to six = 5 h 50
  - each = chacun ; bring = apporter

1. énoncé : "Hi Sam!\nThe film starts at 7:30 pm.\nLet’s meet at 7:15 pm in front of the cinema.\nTom"
   - question : À quelle heure Tom veut-il retrouver Sam ?
   - lu : Hi Sam! The film starts at seven thirty p.m. Let’s meet at seven fifteen p.m. in front of the cinema. Tom.
   - choix : 7 h 15 · 19 h 15 · 19 h 30
   - langue des choix : fr
   - réponse : 19 h 15
   - indice : Let’s meet veut dire « retrouvons-nous ». Trouve sa ligne, puis pense à pm.
   - explication : let’s meet at 7:15 pm = retrouvons-nous à 7 h 15 du soir, soit 19 h 15 (pm : on ajoute 12). 19 h 30, c’est l’heure où le film commence (starts) ; 7 h 15, ce serait le matin.
2. énoncé : "Dear Grandma,\nI’m in Scotland with my class.\nIt’s cold and rainy, but the castles are amazing!\nLove,\nLina"
   - question : Quel temps fait-il en Écosse ?
   - lu : Dear Grandma, I’m in Scotland with my class. It’s cold and rainy, but the castles are amazing! Love, Lina.
   - choix : Il fait froid et il pleut · Il fait chaud et il pleut · Il fait froid et beau
   - langue des choix : fr
   - réponse : Il fait froid et il pleut
   - indice : Cherche la phrase qui commence par It’s : c’est elle qui dit le temps.
   - explication : cold = froid, rainy = pluvieux : il fait froid et il pleut. Amazing parle des châteaux (castles), pas du temps.
3. énoncé : "Hi Emma,\nI can buy the concert tickets for us.\nThey are £12 each.\nJack"
   - question : Combien coûte un billet ?
   - lu : Hi Emma, I can buy the concert tickets for us. They are twelve pounds each. Jack.
   - choix : 2 livres · 12 livres · 24 livres
   - langue des choix : fr
   - réponse : 12 livres
   - indice : Trouve le prix, puis regarde le mot qui le suit : each.
   - explication : £12 each = 12 livres chacun : un billet coûte 12 livres. 24 livres, ce serait le prix des deux billets ; 2 livres oublie le 1 de 12.
4. énoncé : "Hello Hugo,\nWelcome to Bristol!\nPlease bring a towel and warm clothes.\nWe have sheets for your bed.\nSee you on Saturday,\nThe Smith family"
   - question : Qu’est-ce que Hugo doit apporter ?
   - lu : Hello Hugo, welcome to Bristol! Please bring a towel and warm clothes. We have sheets for your bed. See you on Saturday, the Smith family.
   - choix : Une serviette et des vêtements chauds · Des draps pour son lit · Une serviette et des vêtements légers
   - langue des choix : fr
   - réponse : Une serviette et des vêtements chauds
   - indice : Cherche la phrase avec bring, puis lis-la jusqu’au bout.
   - explication : bring a towel and warm clothes = apporte une serviette et des vêtements chauds (warm = chaud). Les draps (sheets), la famille les a déjà : we have.
5. énoncé : "Hi! I’m Mia, I live in Leeds.\nI’m your new pen pal.\nHow are you?"
   - question : Que réponds-tu à la question de Mia ?
   - lu : Hi! I’m Mia, I live in Leeds. I’m your new pen pal. How are you?
   - choix : I’m fine, thanks. And you? · I’m fifteen. And you? · I’m from France. And you?
   - réponse : I’m fine, thanks. And you?
   - indice : How are you? : Mia demande ton âge, d’où tu viens, ou comment tu vas ?
   - explication : How are you? = comment vas-tu ? On répond I’m fine (je vais bien). I’m fifteen répond à How old are you? ; I’m from France répond à Where are you from?
6. énoncé : "Hi! I’m at the bus stop.\nWhat time is it?\nMy phone is dead!\nAva"
   - question : Il est 16 h 20. Que réponds-tu à Ava ?
   - lu : Hi! I’m at the bus stop. What time is it? My phone is dead! Ava.
   - choix : It’s twenty past four. · It’s twenty to four. · It’s twenty to five.
   - réponse : It’s twenty past four.
   - indice : 16 h 20, c’est 4 h 20 de l’après-midi. Relis la ligne de past et to.
   - explication : 16 h 20 = 4 h 20 : twenty past four (past = après). Twenty to four, c’est 3 h 40, et twenty to five, 4 h 40 (to = avant).
7. énoncé : "Hi! I’m selling my old bike.\nIt’s blue and in very good condition.\nKim"
   - question : Tu veux connaître le prix du vélo. Que demandes-tu ?
   - lu : Hi! I’m selling my old bike. It’s blue and in very good condition. Kim.
   - choix : How much is it? · How many is it? · How old is it?
   - réponse : How much is it?
   - indice : Un prix ne se compte pas en objets : much ou many ?
   - explication : How much is it? = combien ça coûte ? How many se dit devant des choses qu’on compte (How many bikes?) ; How old is it? demande son âge.
