# Les prompts des personnages

Un prompt par personnage d’Archipéo, écrit par le consultant Archipéo sur le modèle du prompt du Lion de pierre validé par le mainteneur (essai 5), d’après les règles du lot R6 (`../intentions/r6-personnages.md`). Chaque prompt est donné seul à Z-Image Turbo, une image par prompt, avec la graine 1206 (réglages : `README.md`).

« Déduit » : le personnage n’a pas de fiche R6 ; son métier, son outil, sa couleur ou la forme de son Gardien ont été déduits de son espèce, de la matière de l’île et du code (`src/game/world/characters/species/`).
