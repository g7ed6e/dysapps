# Roadmap artistique et game design

## Phase 1 — Cohérence visuelle

### Objectif

Créer une identité immédiatement reconnaissable pour Blocland.

### Actions

- définir palette ;
- définir typographie ;
- définir composants UI ;
- définir style des îles ;
- définir architecture modulaire ;
- définir style des personnages et créatures ;
- définir règles d'animation.

### Livrable

Mini design system Blocland.

---

## Phase 2 — Carte et écran d'accueil

### Objectif

Faire comprendre l'univers et la progression en quelques secondes.

### Actions

- refondre écran d'accueil ;
- représenter le village ;
- afficher l'archipel ;
- intégrer les trois domaines ;
- rendre la prochaine action évidente.

### Livrable

Écran d'accueil et carte du monde cohérents.

---

## Phase 3 — Boucle pédagogique → construction

### Objectif

Renforcer le lien entre apprentissage et transformation du monde.

### Actions

- associer les réussites à des constructions ;
- améliorer les animations de réparation ;
- montrer les ressources gagnées ;
- rendre les transformations visibles.

### Livrable

Une boucle jouable :

```text
Exercice → réussite → ressource → construction → monde transformé
```

---

## Phase 4 — Vie de l'archipel

### Objectif

Donner une impression de monde vivant.

### Actions

- baleine ;
- oiseaux ;
- animations de mer ;
- météo légère ;
- éclairage ;
- bateaux lointains ;
- phares ;
- habitants.

### Livrable

Des environnements vivants sans surcharge.

---

## Phase 5 — Personnalisation

### Objectif

Créer un attachement durable au village.

### Actions

- personnalisation des bâtiments ;
- décoration ;
- organisation ;
- nom du navire ;
- éléments cosmétiques.

### Livrable

Un village réellement « à soi ».

---

## Phase 6 — Progression 6e → 3e

### Objectif

Faire évoluer la profondeur du jeu avec l'âge.

### Actions

- différencier les archipels ;
- augmenter progressivement l'autonomie ;
- introduire des missions multi-étapes ;
- renforcer la narration ;
- maintenir la même identité mature.

### Livrable

Un univers cohérent sur quatre années.

## Priorités

### P0 — Fondations

- accessibilité ;
- lisibilité ;
- cohérence UI ;
- boucle exercice → monde ;
- âge cible.

### P1 — Expérience

- carte ;
- village ;
- constructions ;
- feedback ;
- baleine.

### P2 — Immersion

- environnement vivant ;
- personnalisation ;
- narration.

### P3 — Enrichissement

- événements ;
- contenu secondaire ;
- collections ;
- éléments cosmétiques.
